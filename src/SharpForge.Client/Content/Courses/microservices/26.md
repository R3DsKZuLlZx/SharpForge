## Retry Pattern

Explains retry with exponential backoff and jitter for transient failures; do not retry non-idempotent operations without safeguards.

```text
Request → Fail → Wait → Retry → Fail → Wait longer → Retry → Success!

Exponential backoff:
- Attempt 1: immediate
- Attempt 2: wait 1s
- Attempt 3: wait 2s
- Attempt 4: wait 4s (with jitter)
```

## Circuit Breaker Pattern

Diagram showing circuit breaker states to prevent cascading failures by short-circuiting calls when error rates are high.

```text
States:
┌────────┐   Failures exceed    ┌────────┐
│ CLOSED │ ──────────────────► │  OPEN  │
│(normal)│                      │ (fail) │
└────┬───┘                      └────┬───┘
     │                               │
     │ ◄─────── Success ─────────────┤
     │                               │
     │    After timeout period       │
     │         ┌──────────┐          │
     └─────────│HALF-OPEN │◄─────────┘
               │  (test)  │
               └──────────┘
```

## Timeout Pattern

Show how to apply a timeout using a CancellationTokenSource to avoid long-hanging requests consuming resources.

```csharp
// Don't wait forever!
using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(5));
var result = await httpClient.GetAsync(url, cts.Token);
```

## Bulkhead Pattern

Discussion and ASCII diagram showing how bulkheads isolate capacity to avoid a failure in one area taking down the whole system.

```text
Isolate resources to prevent cascade failures:

┌───────────────────────────────────────┐
│                Service                │
│  ┌──────────────┐    ┌─────────────┐  │
│  │   API Pool   │    │   DB Pool   │  │
│  │    (10)      │    │     (20)    │  │
│  └──────────────┘    └─────────────┘  │
└───────────────────────────────────────┘

If API pool exhausted, DB operations continue
```
