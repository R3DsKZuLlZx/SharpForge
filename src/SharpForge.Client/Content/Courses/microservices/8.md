## High-Performance Communication with gRPC

HTTP + JSON works well, but for **internal** service-to-service communication where performance and strong contracts matter, **gRPC** is a better choice. It uses HTTP/2 for multiplexing, Protocol Buffers for compact binary serialization, and generates client/server code from `.proto` files.

## Defining a Service with Protocol Buffers

Create a `.proto` file that defines your service contract:

```protobuf
syntax = "proto3";

option csharp_namespace = "InventoryService.Grpc";

package inventory;

service InventoryGrpc {
    rpc GetStock (GetStockRequest) returns (GetStockResponse);
    rpc ReserveStock (ReserveStockRequest) returns (ReserveStockResponse);
    rpc WatchStock (WatchStockRequest) returns (stream StockUpdate);
}

message GetStockRequest {
    int32 product_id = 1;
}

message GetStockResponse {
    int32 product_id = 1;
    int32 available = 2;
    int32 reserved = 3;
}

message ReserveStockRequest {
    int32 product_id = 1;
    int32 quantity = 2;
    string order_id = 3;
}

message ReserveStockResponse {
    bool success = 1;
    string message = 2;
}

message WatchStockRequest {
    int32 product_id = 1;
}

message StockUpdate {
    int32 product_id = 1;
    int32 available = 2;
    string timestamp = 3;
}
```

## Setting Up the gRPC Server

Add the NuGet package and reference the `.proto` file:

```xml
<ItemGroup>
    <PackageReference Include="Grpc.AspNetCore" Version="2.67.0" />
</ItemGroup>

<ItemGroup>
    <Protobuf Include="Protos/inventory.proto" GrpcServices="Server" />
</ItemGroup>
```

Implement the service:

```csharp
public class InventoryGrpcService : InventoryGrpc.InventoryGrpcBase
{
    private readonly IStockRepository _stock;

    public InventoryGrpcService(IStockRepository stock) => _stock = stock;

    public override async Task<GetStockResponse> GetStock(
        GetStockRequest request, ServerCallContext context)
    {
        var stock = await _stock.GetByProductIdAsync(request.ProductId);
        return new GetStockResponse
        {
            ProductId = stock.ProductId,
            Available = stock.Available,
            Reserved = stock.Reserved
        };
    }

    public override async Task<ReserveStockResponse> ReserveStock(
        ReserveStockRequest request, ServerCallContext context)
    {
        var result = await _stock.ReserveAsync(request.ProductId, request.Quantity);
        return new ReserveStockResponse
        {
            Success = result.Succeeded,
            Message = result.Message
        };
    }
}
```

Register the service in `Program.cs`:

```csharp
builder.Services.AddGrpc();

var app = builder.Build();
app.MapGrpcService<InventoryGrpcService>();
app.Run();
```

## Setting Up the gRPC Client

In the calling service, add the client packages and proto reference:

```xml
<ItemGroup>
    <PackageReference Include="Google.Protobuf" Version="3.29.3" />
    <PackageReference Include="Grpc.Net.Client" Version="2.67.0" />
    <PackageReference Include="Grpc.Tools" Version="2.69.0" PrivateAssets="All" />
</ItemGroup>

<ItemGroup>
    <Protobuf Include="Protos/inventory.proto" GrpcServices="Client" />
</ItemGroup>
```

Register and use the typed client:

```csharp
builder.Services.AddGrpcClient<InventoryGrpc.InventoryGrpcClient>(options =>
{
    options.Address = new Uri("http://inventory-service:8080");
});

// Inject and use
public class PlaceOrderHandler
{
    private readonly InventoryGrpc.InventoryGrpcClient _inventory;

    public PlaceOrderHandler(InventoryGrpc.InventoryGrpcClient inventory)
        => _inventory = inventory;

    public async Task<OrderResult> HandleAsync(PlaceOrderCommand command)
    {
        var stock = await _inventory.GetStockAsync(
            new GetStockRequest { ProductId = command.ProductId });

        if (stock.Available < command.Quantity)
            return OrderResult.InsufficientStock();

        var reservation = await _inventory.ReserveStockAsync(new ReserveStockRequest
        {
            ProductId = command.ProductId,
            Quantity = command.Quantity,
            OrderId = command.OrderId.ToString()
        });

        return reservation.Success
            ? OrderResult.Success()
            : OrderResult.ReservationFailed(reservation.Message);
    }
}
```

## Server Streaming

gRPC supports streaming responses — ideal for real-time updates:

```csharp
public override async Task WatchStock(
    WatchStockRequest request,
    IServerStreamWriter<StockUpdate> responseStream,
    ServerCallContext context)
{
    while (!context.CancellationToken.IsCancellationRequested)
    {
        var stock = await _stock.GetByProductIdAsync(request.ProductId);
        await responseStream.WriteAsync(new StockUpdate
        {
            ProductId = stock.ProductId,
            Available = stock.Available,
            Timestamp = DateTime.UtcNow.ToString("O")
        });

        await Task.Delay(5000, context.CancellationToken);
    }
}
```

## Best Practices

- Use gRPC for **internal** service-to-service calls; use REST/JSON for external or browser-facing APIs
- Share `.proto` files via a **shared NuGet package** or a Git submodule
- Use **deadlines** (`context.Deadline`) instead of relying on default timeouts
- Enable **gRPC reflection** in development for tools like `grpcurl`
- Add **retry policies** using the built-in gRPC retry support or Polly
