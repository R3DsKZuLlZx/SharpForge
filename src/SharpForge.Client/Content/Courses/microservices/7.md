## Synchronous Service-to-Service Communication

The simplest way for microservices to talk is over **HTTP**. Service A sends an HTTP request to Service B and waits for the response. It's familiar, well-tooled, and works great for request-response interactions.

## IHttpClientFactory

Never create `HttpClient` instances manually — it causes **socket exhaustion**. Use `IHttpClientFactory` instead:

```csharp
// ❌ BAD: Creates a new HttpClient per request
var client = new HttpClient();
var response = await client.GetAsync("http://inventory-service/api/stock/123");

// ✅ GOOD: Use IHttpClientFactory
builder.Services.AddHttpClient();

// In your service
public class OrderService
{
    private readonly IHttpClientFactory _factory;

    public OrderService(IHttpClientFactory factory) => _factory = factory;

    public async Task<StockLevel?> GetStockAsync(int productId)
    {
        var client = _factory.CreateClient();
        var response = await client.GetAsync($"http://inventory-service:8080/api/stock/{productId}");
        response.EnsureSuccessStatusCode();
        return await response.Content.ReadFromJsonAsync<StockLevel>();
    }
}
```

## Named Clients

Configure clients with base addresses and default headers:

```csharp
builder.Services.AddHttpClient("InventoryService", client =>
{
    client.BaseAddress = new Uri("http://inventory-service:8080");
    client.DefaultRequestHeaders.Add("Accept", "application/json");
    client.Timeout = TimeSpan.FromSeconds(10);
});

// Usage
var client = _factory.CreateClient("InventoryService");
var stock = await client.GetFromJsonAsync<StockLevel>($"/api/stock/{productId}");
```

## Typed Clients

The cleanest approach — encapsulate HTTP calls in a dedicated class:

```csharp
public class InventoryClient
{
    private readonly HttpClient _client;

    public InventoryClient(HttpClient client) => _client = client;

    public async Task<StockLevel?> GetStockAsync(int productId, CancellationToken ct = default)
    {
        var response = await _client.GetAsync($"/api/stock/{productId}", ct);
        response.EnsureSuccessStatusCode();
        return await response.Content.ReadFromJsonAsync<StockLevel>(ct);
    }

    public async Task<bool> ReserveStockAsync(int productId, int quantity, CancellationToken ct = default)
    {
        var response = await _client.PostAsJsonAsync("/api/stock/reserve",
            new { ProductId = productId, Quantity = quantity }, ct);
        return response.IsSuccessStatusCode;
    }
}

// Registration
builder.Services.AddHttpClient<InventoryClient>(client =>
{
    client.BaseAddress = new Uri("http://inventory-service:8080");
    client.Timeout = TimeSpan.FromSeconds(10);
});
```

Now inject `InventoryClient` directly:

```csharp
public class PlaceOrderHandler
{
    private readonly InventoryClient _inventory;

    public PlaceOrderHandler(InventoryClient inventory) => _inventory = inventory;

    public async Task<OrderResult> HandleAsync(PlaceOrderCommand command, CancellationToken ct)
    {
        var stock = await _inventory.GetStockAsync(command.ProductId, ct);
        if (stock is null || stock.Available < command.Quantity)
            return OrderResult.InsufficientStock();

        var reserved = await _inventory.ReserveStockAsync(command.ProductId, command.Quantity, ct);
        if (!reserved)
            return OrderResult.ReservationFailed();

        // ... create the order
        return OrderResult.Success(order.Id);
    }
}
```

## Service Discovery

In Docker Compose, service names are hostnames. In Kubernetes, use the Kubernetes service name. Keep base URLs in configuration:

```json
{
  "ServiceUrls": {
    "Inventory": "http://inventory-service:8080",
    "Payment": "http://payment-service:8080"
  }
}
```

```csharp
builder.Services.AddHttpClient<InventoryClient>((sp, client) =>
{
    var config = sp.GetRequiredService<IConfiguration>();
    client.BaseAddress = new Uri(config["ServiceUrls:Inventory"]!);
});
```

## Error Handling

Always handle failures — the remote service may be down, slow, or returning errors:

```csharp
public async Task<StockLevel?> GetStockAsync(int productId, CancellationToken ct)
{
    try
    {
        var response = await _client.GetAsync($"/api/stock/{productId}", ct);

        if (response.StatusCode == HttpStatusCode.NotFound)
            return null;

        response.EnsureSuccessStatusCode();
        return await response.Content.ReadFromJsonAsync<StockLevel>(ct);
    }
    catch (HttpRequestException ex)
    {
        // Log the error and return a sensible default or throw a domain exception
        _logger.LogError(ex, "Failed to get stock for product {ProductId}", productId);
        throw new ServiceUnavailableException("Inventory service is unavailable", ex);
    }
    catch (TaskCanceledException) when (!ct.IsCancellationRequested)
    {
        _logger.LogWarning("Inventory service request timed out for product {ProductId}", productId);
        throw new ServiceUnavailableException("Inventory service timed out");
    }
}
```

<div class="warning-box">
    <div class="warning-box-header"><span>⚠️ Important</span></div>
    <p>HTTP is <strong>synchronous</strong>. If Service B is down, Service A's request fails immediately. For fire-and-forget scenarios or when you can tolerate eventual delivery, use asynchronous messaging instead (covered in Lesson 9).</p>
</div>

## Best Practices

- **Always use `IHttpClientFactory`** — never `new HttpClient()`
- Prefer **typed clients** for clean, testable service-to-service calls
- **Set timeouts** on every client to avoid hanging requests
- **Pass `CancellationToken`** through the entire call chain
- Keep service URLs in **configuration**, not hardcoded
- Add **retry and circuit-breaker policies** (we'll cover Polly in Lesson 27)
