## Securing a Distributed System

In a monolith, authentication happens once. In microservices, every service is a potential entry point. You need a centralized **identity provider** that issues tokens, and a consistent strategy for validating them across services.

## The Architecture

```
Client ──▶ Identity Provider ──▶ JWT Token
  │
  └──▶ API Gateway (validates token) ──▶ OrderService (trusts gateway)
                                      ──▶ InventoryService (trusts gateway)
```

## JWT Token Validation

Each service validates incoming JWT tokens:

```csharp
builder.Services.AddAuthentication("Bearer")
    .AddJwtBearer(options =>
    {
        options.Authority = "http://identity-server";
        options.Audience = "order-service";
        options.RequireHttpsMetadata = false; // dev only

        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuer = true,
            ValidateAudience = true,
            ValidateLifetime = true,
            ClockSkew = TimeSpan.FromSeconds(30)
        };
    });

builder.Services.AddAuthorization();

var app = builder.Build();
app.UseAuthentication();
app.UseAuthorization();
```

## Claims-Based Authorization

Use claims from the JWT for fine-grained access control:

```csharp
// Policy-based authorization
builder.Services.AddAuthorization(options =>
{
    options.AddPolicy("CanManageOrders", policy =>
        policy.RequireClaim("scope", "orders.write"));

    options.AddPolicy("AdminOnly", policy =>
        policy.RequireRole("admin"));
});

// Apply to endpoints
app.MapPost("/api/orders", [Authorize(Policy = "CanManageOrders")] async (
    PlaceOrderRequest request, IOrderService orders) =>
{
    var result = await orders.PlaceAsync(request);
    return Results.Created($"/api/orders/{result.Id}", result);
});

app.MapDelete("/api/orders/{id}", [Authorize(Policy = "AdminOnly")] async (
    Guid id, IOrderService orders) =>
{
    await orders.DeleteAsync(id);
    return Results.NoContent();
});
```

## Extracting User Info from Tokens

Access the authenticated user's claims in your services:

```csharp
app.MapGet("/api/orders/mine", async (
    ClaimsPrincipal user, IOrderRepository orders) =>
{
    var userId = user.FindFirst("sub")?.Value
        ?? throw new UnauthorizedAccessException();

    var userOrders = await orders.GetByCustomerAsync(Guid.Parse(userId));
    return Results.Ok(userOrders);
});
```

## Service-to-Service Authentication

When services call each other, they use the **client credentials** flow — no user is involved:

```csharp
// Register a typed client that acquires tokens automatically
builder.Services.AddHttpClient<InventoryClient>(client =>
{
    client.BaseAddress = new Uri("http://inventory-service:8080");
})
.AddHttpMessageHandler<ClientCredentialsHandler>();

// The handler acquires and caches tokens
public class ClientCredentialsHandler : DelegatingHandler
{
    private readonly ITokenService _tokenService;

    public ClientCredentialsHandler(ITokenService tokenService)
        => _tokenService = tokenService;

    protected override async Task<HttpResponseMessage> SendAsync(
        HttpRequestMessage request, CancellationToken ct)
    {
        var token = await _tokenService.GetClientTokenAsync("inventory-api", ct);
        request.Headers.Authorization = new AuthenticationHeaderValue("Bearer", token);
        return await base.SendAsync(request, ct);
    }
}
```

## Token Propagation

When a user request triggers calls to other services, propagate the user's token:

```csharp
builder.Services.AddHttpClient<InventoryClient>(client =>
{
    client.BaseAddress = new Uri("http://inventory-service:8080");
})
.AddHttpMessageHandler<TokenPropagationHandler>();

public class TokenPropagationHandler : DelegatingHandler
{
    private readonly IHttpContextAccessor _httpContextAccessor;

    public TokenPropagationHandler(IHttpContextAccessor httpContextAccessor)
        => _httpContextAccessor = httpContextAccessor;

    protected override async Task<HttpResponseMessage> SendAsync(
        HttpRequestMessage request, CancellationToken ct)
    {
        var token = await _httpContextAccessor.HttpContext!
            .GetTokenAsync("access_token");

        if (!string.IsNullOrEmpty(token))
            request.Headers.Authorization = new AuthenticationHeaderValue("Bearer", token);

        return await base.SendAsync(request, ct);
    }
}
```

## Best Practices

- Use a **centralized identity provider** — don't roll your own authentication
- Validate tokens **at the gateway and each service** (defense in depth)
- Use **scopes** for API permissions and **roles/claims** for user authorization
- Use **client credentials** for service-to-service calls, **authorization code** for user-facing clients
- **Propagate the user token** downstream when the request is on behalf of a user
- **Rotate secrets** and use short-lived tokens (5–15 minutes)
