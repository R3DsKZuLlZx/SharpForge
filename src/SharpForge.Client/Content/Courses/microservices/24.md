## OpenTelemetry Setup

Shows how to register OpenTelemetry tracing in a .NET app and export spans to an OTLP-compatible backend like Jaeger.

```csharp
// Program.cs
builder.Services.AddOpenTelemetry()
    .WithTracing(tracing =>
    {
        tracing
            .AddAspNetCoreInstrumentation()
            .AddHttpClientInstrumentation()
            .AddSqlClientInstrumentation()
            .AddSource("OrderService")
            .AddOtlpExporter(opts =>
            {
                opts.Endpoint = new Uri("http://jaeger:4317");
            });
    });
```

## Custom Spans

Example showing how to create a custom activity/span for a business operation and add tags and events for richer trace context.

```csharp
public class OrderService
{
    private static readonly ActivitySource Source = new("OrderService");

    public async Task ProcessOrderAsync(Order order)
    {
        using var activity = Source.StartActivity("ProcessOrder");
        activity?.SetTag("order.id", order.Id.ToString());
        activity?.SetTag("order.total", order.Total);
        
        // Process order...
        
        activity?.AddEvent(new ActivityEvent("OrderValidated"));
    }
}
```
