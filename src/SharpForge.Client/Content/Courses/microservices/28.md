## Services Overview

- **API Gateway (YARP):** Routing, auth, rate limiting
- **Order Service:** Order management, saga orchestration
- **Inventory Service:** Stock management (gRPC)
- **Payment Service:** Payment processing
- **Notification Service:** Email/SMS (event-driven)
- **Identity Service:** Authentication (Duende IdentityServer)

## Order Flow (Saga)

Sequence of events illustrating how the saga coordinates steps like reservation, payment, and compensation when failures occur.

```text
1. OrderSubmitted
   └─► ReserveInventory (gRPC)
       ├─► InventoryReserved
       │   └─► ProcessPayment
       │       ├─► PaymentSucceeded
       │       │   └─► CompleteOrder → SendNotification
       │       └─► PaymentFailed
       │           └─► ReleaseInventory (compensate)
       └─► InventoryInsufficient
           └─► RejectOrder
```

docker-compose sample that lists services for local development including message broker, databases, tracing and metrics stacks.
