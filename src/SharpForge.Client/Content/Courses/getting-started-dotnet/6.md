## Console Applications
Console applications are text-based programs that run in a terminal. They're perfect for learning, automation scripts, CLI tools, and background services.
## Creating a Console App
```bash
# Create a new console application
dotnet new console -n MyConsoleApp
cd MyConsoleApp

# Run it
dotnet run```
The generated <code>Program.cs</code>:
```csharp
// Modern top-level statements (default in .NET 6+)
Console.WriteLine("Hello, World!");```
## Console Output
The <code>Console</code> class provides methods for output:
```csharp
// Basic output
Console.WriteLine("This prints with a newline");
Console.Write("This prints without a newline");

// String interpolation
string name = "Alice";
int age = 30;
Console.WriteLine($"Name: {name}, Age: {age}");

// Formatting numbers
decimal price = 19.99m;
Console.WriteLine($"Price: {price:C}");      // Currency: $19.99
Console.WriteLine($"Percent: {0.156:P}");    // Percent: 15.60%
Console.WriteLine($"Padded: {42:D5}");       // Padded: 00042

// Formatting dates
DateTime now = DateTime.Now;
Console.WriteLine($"Date: {now:yyyy-MM-dd}");
Console.WriteLine($"Time: {now:HH:mm:ss}");```
## Console Input
```csharp
// Read a line of text
Console.Write("Enter your name: ");
string? name = Console.ReadLine();
Console.WriteLine($"Hello, {name}!");

// Read a single key
Console.WriteLine("Press any key to continue...");
ConsoleKeyInfo key = Console.ReadKey();
Console.WriteLine($"\nYou pressed: {key.Key}");

// Parse numeric input
Console.Write("Enter your age: ");
if (int.TryParse(Console.ReadLine(), out int age))
{
    Console.WriteLine($"You are {age} years old");
}
else
{
    Console.WriteLine("Invalid age entered");
}```
## Console Colors
```csharp
// Change text color
Console.ForegroundColor = ConsoleColor.Green;
Console.WriteLine("Success!");

Console.ForegroundColor = ConsoleColor.Red;
Console.WriteLine("Error!");

Console.ForegroundColor = ConsoleColor.Yellow;
Console.WriteLine("Warning!");

// Reset to default
Console.ResetColor();
Console.WriteLine("Back to normal");

// Background color
Console.BackgroundColor = ConsoleColor.DarkBlue;
Console.ForegroundColor = ConsoleColor.White;
Console.WriteLine("White on blue");
Console.ResetColor();```
## Command-Line Arguments
Access arguments passed to your program:
```csharp
// Using top-level statements, args is available automatically
foreach (string arg in args)
{
    Console.WriteLine($"Argument: {arg}");
}

// Or with explicit Main method
class Program
{
    static void Main(string[] args)
    {
        if (args.Length == 0)
        {
            Console.WriteLine("Usage: myapp <name>");
            return;
        }

        Console.WriteLine($"Hello, {args[0]}!");
    }
}```
```bash
# Run with arguments
dotnet run -- Alice Bob Charlie

# Or after publishing
./myapp Alice Bob Charlie```
## Using System.CommandLine
For complex CLI tools, use the <code>System.CommandLine</code> package:
```bash
dotnet add package System.CommandLine```
```csharp
using System.CommandLine;

var nameOption = new Option<string>(
    name: "--name",
    description: "Your name")
{ IsRequired = true };

var ageOption = new Option<int>(
    name: "--age",
    description: "Your age",
    getDefaultValue: () => 0);

var rootCommand = new RootCommand("A sample CLI application")
{
    nameOption,
    ageOption
};

rootCommand.SetHandler((name, age) =>
{
    Console.WriteLine($"Hello, {name}!");
    if (age > 0)
        Console.WriteLine($"You are {age} years old.");
}, nameOption, ageOption);

return await rootCommand.InvokeAsync(args);```
```bash
# Usage examples
dotnet run -- --name Alice --age 30
dotnet run -- --help```
## Exit Codes
Return exit codes to indicate success or failure:
```csharp
// Top-level statements can return int
if (args.Length == 0)
{
    Console.Error.WriteLine("Error: No arguments provided");
    return 1; // Non-zero indicates error
}

Console.WriteLine($"Processing: {args[0]}");
return 0; // Zero indicates success```
```bash
# Check exit code in shell
dotnet run -- myarg
echo $?  # Linux/Mac
echo $LASTEXITCODE  # PowerShell```
## Building a Complete Example
Let's build a simple task list application:
```csharp
List<string> tasks = [];

while (true)
{
    Console.Clear();
    Console.ForegroundColor = ConsoleColor.Cyan;
    Console.WriteLine("=== Task Manager ===\n");
    Console.ResetColor();

    // Display tasks
    if (tasks.Count == 0)
    {
        Console.WriteLine("No tasks yet.\n");
    }
    else
    {
        for (int i = 0; i < tasks.Count; i++)
        {
            Console.WriteLine($"  {i + 1}. {tasks[i]}");
        }
        Console.WriteLine();
    }

    // Menu
    Console.WriteLine("Commands: [A]dd, [R]emove, [Q]uit");
    Console.Write("Enter command: ");

    var key = Console.ReadKey();
    Console.WriteLine();

    switch (char.ToUpper(key.KeyChar))
    {
        case 'A':
            Console.Write("Enter task: ");
            var task = Console.ReadLine();
            if (!string.IsNullOrWhiteSpace(task))
tasks.Add(task);
            break;

        case 'R':
            Console.Write("Enter task number to remove: ");
            if (int.TryParse(Console.ReadLine(), out int num)
&& num > 0 && num <= tasks.Count)
tasks.RemoveAt(num - 1);
            break;

        case 'Q':
            Console.WriteLine("Goodbye!");
            return;
    }
}```
