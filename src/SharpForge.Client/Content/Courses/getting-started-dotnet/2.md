## Setting Up Your Development Environment

Before you can start building .NET applications, you need to install the .NET SDK (Software Development Kit). The SDK includes everything you need: the runtime, libraries, and command-line tools.

In this lesson, we'll walk through installing .NET on Windows, macOS, and Linux, then verify the installation is working correctly.

## Installing on Windows

There are several ways to install .NET on Windows:

### Option 1: Using the Installer (Recommended)

1. Visit [dotnet.microsoft.com/download](https://dotnet.microsoft.com/download)
2. Click "Download .NET SDK" for the latest version
3. Run the downloaded installer
4. Follow the installation wizard

### Option 2: Using Windows Package Manager (winget)

```bash
# Install the latest .NET SDK
winget install Microsoft.DotNet.SDK.8

# Or install a specific version
winget install Microsoft.DotNet.SDK.9
```

### Option 3: Using Chocolatey

```bash
# Install using Chocolatey
choco install dotnet-sdk
```

## Installing on macOS

macOS users have these installation options:

### Option 1: Using the Installer

1. Visit [dotnet.microsoft.com/download](https://dotnet.microsoft.com/download)
2. Download the macOS installer (.pkg file)
3. Double-click to run and follow the prompts

### Option 2: Using Homebrew (Recommended)

```bash
# Install the latest .NET SDK
brew install --cask dotnet-sdk

# Verify installation
dotnet --version
```

## Installing on Linux

Linux installation varies by distribution:

### Ubuntu / Debian

```bash
# Add Microsoft package repository
wget https://packages.microsoft.com/config/ubuntu/22.04/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
rm packages-microsoft-prod.deb

# Install the SDK
sudo apt-get update
sudo apt-get install -y dotnet-sdk-8.0
```

### Fedora

```bash
# Install using dnf
sudo dnf install dotnet-sdk-8.0
```

### Using the Install Script (Any Distribution)

```bash
# Download and run the install script
wget https://dot.net/v1/dotnet-install.sh -O dotnet-install.sh
chmod +x dotnet-install.sh
./dotnet-install.sh --channel 8.0

# Add to PATH (add to ~/.bashrc or ~/.zshrc)
export DOTNET_ROOT=$HOME/.dotnet
export PATH=$PATH:$DOTNET_ROOT:$DOTNET_ROOT/tools
```

## Verifying Your Installation

After installation, open a new terminal window and run these commands to verify everything is working:

```bash
# Check the installed SDK version
dotnet --version

# See all installed SDKs and runtimes
dotnet --info

# List available SDKs
dotnet --list-sdks

# List available runtimes
dotnet --list-runtimes
```

You should see output similar to:

```bash
$ dotnet --version
8.0.100

$ dotnet --list-sdks
8.0.100 [/usr/share/dotnet/sdk]

$ dotnet --list-runtimes
Microsoft.AspNetCore.App 8.0.0 [/usr/share/dotnet/shared/Microsoft.AspNetCore.App]
Microsoft.NETCore.App 8.0.0 [/usr/share/dotnet/shared/Microsoft.NETCore.App]
```

2. Open VS Code and go to Extensions (Ctrl+Shift+X)
3. Search for and install "C# Dev Kit"

## Troubleshooting Common Issues

### 'dotnet' is not recognized

If you see this error, the .NET SDK isn't in your PATH:

- **Windows:** Restart your terminal or computer
- **macOS/Linux:** Add the dotnet path to your shell profile

### Multiple SDK Versions

You can have multiple .NET versions installed side by side. Use a `global.json` file to pin a specific version for a project:

```json
{
  "sdk": {
    "version": "8.0.100",
    "rollForward": "latestFeature"
  }
}
```

### Permission Issues on Linux/Mac

If you get permission errors, don't use `sudo` with dotnet commands. Instead, ensure your user owns the .dotnet directory:

```bash
sudo chown -R $(whoami) ~/.dotnet
```
