## What is ASP.NET Core?
ASP.NET Core is a cross-platform, high-performance framework for building modern web applications and APIs. It's the web development framework for .NET, enabling you to build everything from REST APIs to full-stack web applications.

## Creating Your First API
```bash
# Create a minimal API project
dotnet new web -n MyFirstApi
cd MyFirstApi
dotnet run```
The generated <code>Program.cs</code>:
```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

app.MapGet("/", () => "Hello World!");

app.Run();```
Visit <code>http://localhost:5000</code> to see your API running!
## The Application Pipeline
ASP.NET Core uses a pipeline of middleware components to handle requests:
<div class="pipeline-diagram">
<div class="pipeline-step">Request</div>
<div class="pipeline-arrow">→</div>
<div class="pipeline-step">Middleware 1</div>
<div class="pipeline-arrow">→</div>
<div class="pipeline-step">Middleware 2</div>
<div class="pipeline-arrow">→</div>
<div class="pipeline-step">Endpoint</div>
<div class="pipeline-arrow">→</div>
<div class="pipeline-step">Response</div>
</div>
```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

// Middleware order matters!
app.UseHttpsRedirection();  // Redirect HTTP to HTTPS
app.UseStaticFiles();       // Serve static files
app.UseRouting();           // Enable routing
app.UseAuthentication();    // Who is the user?
app.UseAuthorization();     // Can they access this?

app.MapGet("/", () => "Hello World!");

app.Run();```
## Minimal APIs
Minimal APIs provide a lightweight way to build HTTP APIs:
```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

// Simple GET endpoint
app.MapGet("/hello", () => "Hello, World!");

// With route parameters
app.MapGet("/hello/{name}", (string name) => $"Hello, {name}!");

// POST endpoint with body
app.MapPost("/users", (User user) =>
{
    // Create user...
    return Results.Created($"/users/{user.Id}", user);
});

// With query parameters
app.MapGet("/search", (string? query, int page = 1) =>
    $"Searching for: {query}, page {page}");

// Return different status codes
app.MapGet("/users/{id}", (int id) =>
{
    var user = GetUser(id);
    return user is not null
        ? Results.Ok(user)
        : Results.NotFound();
});

app.Run();

record User(int Id, string Name, string Email);```
## Dependency Injection
ASP.NET Core has built-in dependency injection:
```csharp
var builder = WebApplication.CreateBuilder(args);

// Register services
builder.Services.AddScoped<IUserService, UserService>();
builder.Services.AddSingleton<ICache, MemoryCache>();

var app = builder.Build();

// Inject into endpoints
app.MapGet("/users", (IUserService userService) =>
    userService.GetAllUsers());

app.MapGet("/users/{id}", async (int id, IUserService userService) =>
{
    var user = await userService.GetByIdAsync(id);
    return user is not null ? Results.Ok(user) : Results.NotFound();
});

app.Run();```
## Controller-Based APIs
For larger APIs, controllers provide better organization:
```bash
dotnet new webapi -n MyApi --use-controllers```
```csharp
// Controllers/UsersController.cs
using Microsoft.AspNetCore.Mvc;

[ApiController]
[Route("api/[controller]")]
public class UsersController : ControllerBase
{
    private readonly IUserService _userService;

    public UsersController(IUserService userService)
    {
        _userService = userService;
    }

    [HttpGet]
    public async Task<ActionResult<IEnumerable<User>>> GetAll()
    {
        return Ok(await _userService.GetAllAsync());
    }

    [HttpGet("{id}")]
    public async Task<ActionResult<User>> GetById(int id)
    {
        var user = await _userService.GetByIdAsync(id);
        if (user == null) return NotFound();
        return Ok(user);
    }

    [HttpPost]
    public async Task<ActionResult<User>> Create(CreateUserDto dto)
    {
        var user = await _userService.CreateAsync(dto);
        return CreatedAtAction(nameof(GetById), new { id = user.Id }, user);
    }
}```
## Configuration in Web Apps
ASP.NET Core automatically loads configuration:
```csharp
var builder = WebApplication.CreateBuilder(args);

// Configuration is already available
var connectionString = builder.Configuration.GetConnectionString("Default");

// Use options pattern
builder.Services.Configure<MySettings>(
    builder.Configuration.GetSection("MySettings"));

var app = builder.Build();

// Access configuration in endpoints
app.MapGet("/config", (IConfiguration config) =>
    config["MySettings:ApiKey"]);

app.Run();```
## Running and Testing
```bash
# Run the application
dotnet run

# Run with hot reload
dotnet watch run

# Run on specific port
dotnet run --urls "http://localhost:3000"```
Test with curl or a tool like Postman:
```bash
# GET request
curl http://localhost:5000/hello

# POST request with JSON body
curl -X POST http://localhost:5000/users \
  -H "Content-Type: application/json" \
  -d '{"name": "Alice", "email": "alice@example.com"}'```
## OpenAPI / Swagger
Add API documentation with Swagger:
```csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddEndpointsApiExplorer();
builder.Services.AddSwaggerGen();

var app = builder.Build();

if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI();
}

app.MapGet("/hello", () => "Hello World!")
    .WithName("GetHello")
    .WithOpenApi();

app.Run();```
Visit <code>/swagger</code> to see interactive API documentation!
