## Configuration in .NET
.NET provides a flexible configuration system that supports multiple sources: JSON files, environment variables, command-line arguments, and more. This allows you to easily manage settings across different environments.
## Setting Up Configuration
First, add the required packages:
```bash
dotnet add package Microsoft.Extensions.Configuration
dotnet add package Microsoft.Extensions.Configuration.Json
dotnet add package Microsoft.Extensions.Configuration.EnvironmentVariables```
Create an <code>appsettings.json</code> file:
```json
{
  "AppSettings": {
    "ApplicationName": "My App",
    "MaxRetries": 3,
    "EnableFeatureX": true
  },
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=MyDb"
  },
  "Logging": {
    "LogLevel": "Information"
  }
}```
Make sure the file is copied to output:
```xml
<ItemGroup>
  <None Update="appsettings.json">
    <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
  </None>
</ItemGroup>```
## Reading Configuration
```csharp
using Microsoft.Extensions.Configuration;

// Build configuration
IConfiguration config = new ConfigurationBuilder()
    .SetBasePath(Directory.GetCurrentDirectory())
    .AddJsonFile("appsettings.json", optional: false)
    .AddJsonFile($"appsettings.{Environment.GetEnvironmentVariable("DOTNET_ENVIRONMENT")}.json", optional: true)
    .AddEnvironmentVariables()
    .Build();

// Read values
string appName = config["AppSettings:ApplicationName"];
int maxRetries = config.GetValue<int>("AppSettings:MaxRetries");
string connectionString = config.GetConnectionString("DefaultConnection");

Console.WriteLine($"App: {appName}");
Console.WriteLine($"Max Retries: {maxRetries}");
Console.WriteLine($"Connection: {connectionString}");```
## Environment-Specific Configuration
Create environment-specific files that override base settings:
```bash
appsettings.json                 # Base settings
appsettings.Development.json     # Development overrides
appsettings.Production.json      # Production overrides```
Example <code>appsettings.Development.json</code>:
```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=MyDb_Dev"
  },
  "Logging": {
    "LogLevel": "Debug"
  }
}```
Set the environment via:
```bash
# Windows PowerShell
$env:DOTNET_ENVIRONMENT = "Development"

# Linux/Mac
export DOTNET_ENVIRONMENT=Development

# In launchSettings.json for development
"environmentVariables": {
  "DOTNET_ENVIRONMENT": "Development"
}```
## The Options Pattern
The Options pattern provides strongly-typed access to configuration sections:
```bash
dotnet add package Microsoft.Extensions.Options```
```csharp
// Define options class
public class AppSettings
{
    public string ApplicationName { get; set; } = "";
    public int MaxRetries { get; set; }
    public bool EnableFeatureX { get; set; }
}

// Bind configuration to options
var appSettings = new AppSettings();
config.GetSection("AppSettings").Bind(appSettings);

// Or use Get<T>()
var settings = config.GetSection("AppSettings").Get<AppSettings>();

Console.WriteLine($"App: {settings?.ApplicationName}");
Console.WriteLine($"Feature X: {settings?.EnableFeatureX}");```
## Using with Dependency Injection
In hosted applications, use the Options pattern with DI:
```csharp
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Hosting;
using Microsoft.Extensions.Options;

var builder = Host.CreateApplicationBuilder(args);

// Register options
builder.Services.Configure<AppSettings>(
    builder.Configuration.GetSection("AppSettings"));

var host = builder.Build();

// Resolve options
var options = host.Services.GetRequiredService<IOptions<AppSettings>>();
Console.WriteLine($"App: {options.Value.ApplicationName}");```
## Environment Variables
Environment variables can override any configuration value:
```bash
# Override AppSettings:MaxRetries
$env:AppSettings__MaxRetries = "5"

# Note: Use double underscore (__) for nested keys```
Configuration sources are layered—later sources override earlier ones:
<div class="config-priority">
<div class="priority-item">1. appsettings.json (lowest priority)</div>
<div class="priority-item">2. appsettings.{Environment}.json</div>
<div class="priority-item">3. Environment variables</div>
<div class="priority-item">4. Command-line arguments (highest priority)</div>
</div>
## User Secrets (Development)
For sensitive data during development, use User Secrets:
```bash
# Initialize user secrets
dotnet user-secrets init

# Set a secret
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Server=secret"

# List secrets
dotnet user-secrets list

# Remove a secret
dotnet user-secrets remove "ConnectionStrings:DefaultConnection"```
Add to configuration:
```csharp
var config = new ConfigurationBuilder()
    .AddJsonFile("appsettings.json")
    .AddUserSecrets<Program>() // Only in Development
    .Build();```
<div class="warning-box">
<div class="warning-box-header">
<span>⚠️ Important</span>
</div>
User Secrets are stored outside your project folder and should only be used during development. For production, use environment variables or a secrets manager like Azure Key Vault.
</div>
## Command-Line Configuration
```bash
dotnet add package Microsoft.Extensions.Configuration.CommandLine```
```csharp
var config = new ConfigurationBuilder()
    .AddJsonFile("appsettings.json")
    .AddCommandLine(args)
    .Build();```
```bash
# Override settings via command line
dotnet run -- --AppSettings:MaxRetries=10 --Logging:LogLevel=Debug```
