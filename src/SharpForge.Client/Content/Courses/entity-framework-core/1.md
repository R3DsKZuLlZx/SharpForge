## What is Entity Framework Core?

Entity Framework Core (EF Core) is a modern, lightweight, extensible, and cross-platform Object-Relational Mapper (ORM) for .NET. It enables developers to work with databases using .NET objects, eliminating most of the data-access code.

## How EF Core Works

This snippet shows how a LINQ query in C# is translated by EF Core into SQL; it's an example of how developers write expressive C# while EF Core generates the SQL behind the scenes.

```csharp
// Your C# code
var products = await context.Products
    .Where(p => p.Price > 100)
    .OrderBy(p => p.Name)
    .ToListAsync();

// EF Core generates SQL
// SELECT * FROM Products WHERE Price > 100 ORDER BY Name
```

## Supported Databases

- **SQL Server** - Microsoft.EntityFrameworkCore.SqlServer
- **PostgreSQL** - Npgsql.EntityFrameworkCore.PostgreSQL
- **SQLite** - Microsoft.EntityFrameworkCore.Sqlite
- **MySQL** - Pomelo.EntityFrameworkCore.MySql
- **Cosmos DB** - Microsoft.EntityFrameworkCore.Cosmos
- **In-Memory** - Microsoft.EntityFrameworkCore.InMemory (testing)

## Installing EF Core

Install the core EF package, a provider for your database, and the design-time tools used for migrations and scaffolding. The CLI tool `dotnet-ef` is handy for migrations.

```bash
# Core package
dotnet add package Microsoft.EntityFrameworkCore

# Database provider (pick one)
dotnet add package Microsoft.EntityFrameworkCore.SqlServer
dotnet add package Microsoft.EntityFrameworkCore.Sqlite

# Design-time tools for migrations
dotnet add package Microsoft.EntityFrameworkCore.Design

# CLI tools (global)
dotnet tool install --global dotnet-ef
```

## Core Concepts

- **DbContext:** The main class that coordinates EF Core functionality
- **DbSet&lt;T&gt;:** Represents a table in the database
- **Entity:** A class that maps to a database table
- **Migration:** A way to update the database schema
- **Change Tracker:** Tracks modifications to entities
