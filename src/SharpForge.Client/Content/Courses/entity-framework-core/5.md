## Create (Insert)

Use `Add`/`AddRange` for tracked inserts and call `SaveChangesAsync` to persist; new entity keys are populated after saving.

```csharp
// Single entity
var product = new Product { Name = "Laptop", Price = 999.99m };
context.Products.Add(product);
await context.SaveChangesAsync();
// product.Id is now set

// Multiple entities
var products = new List<Product>
{
    new() { Name = "Mouse", Price = 29.99m },
    new() { Name = "Keyboard", Price = 79.99m }
};
context.Products.AddRange(products);
await context.SaveChangesAsync();
```

## Read (Query)

Use `FindAsync` for primary key lookups and LINQ methods for conditional queries; prefer async variants to avoid blocking threads.

```csharp
// Get all
var allProducts = await context.Products.ToListAsync();

// Get by primary key (most efficient)
var product = await context.Products.FindAsync(id);

// Get single with condition
var laptop = await context.Products
    .FirstOrDefaultAsync(p => p.Name == "Laptop");

// Get single (throws if not exactly one)
var single = await context.Products
    .SingleOrDefaultAsync(p => p.Id == id);

// Check existence
var exists = await context.Products.AnyAsync(p => p.Id == id);
```

## Update

Modify tracked entities directly and call `SaveChangesAsync`; for disconnected scenarios use `Update` or attach the entity and mark specific properties modified.

```csharp
// Tracked entity (recommended)
var product = await context.Products.FindAsync(id);
if (product != null)
{
    product.Price = 899.99m;
    product.Name = "Gaming Laptop";
    await context.SaveChangesAsync();
}

// Disconnected entity
public async Task UpdateProductAsync(Product product)
{
    context.Products.Update(product);
    await context.SaveChangesAsync();
}

// Update specific properties only
context.Entry(product).Property(p => p.Price).IsModified = true;
```

## Delete

Remove tracked entities or use bulk delete APIs (EF Core 7+) for efficient server-side deletions without loading entities.

```csharp
// With tracking
var product = await context.Products.FindAsync(id);
if (product != null)
{
    context.Products.Remove(product);
    await context.SaveChangesAsync();
}

// Without loading (EF Core 7+)
await context.Products
    .Where(p => p.Id == id)
    .ExecuteDeleteAsync();

// Bulk delete
await context.Products
    .Where(p => p.Price < 10)
    .ExecuteDeleteAsync();
```

## Bulk Update (EF Core 7+)

Use `ExecuteUpdateAsync` to perform server-side bulk updates efficiently without loading entities into memory.

```csharp
// Update all products in category
await context.Products
    .Where(p => p.CategoryId == categoryId)
    .ExecuteUpdateAsync(setters => setters
        .SetProperty(p => p.Price, p => p.Price * 1.1m)
        .SetProperty(p => p.UpdatedAt, DateTime.UtcNow));
```
