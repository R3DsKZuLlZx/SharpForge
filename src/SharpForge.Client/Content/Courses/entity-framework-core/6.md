## Filtering with Where

Use `Where` to apply filters that translate to SQL WHERE clauses; combine expressions for complex filters.

```csharp
// Simple filter
var expensiveProducts = await context.Products
    .Where(p => p.Price > 100)
    .ToListAsync();

// Multiple conditions
var activeExpensive = await context.Products
    .Where(p => p.Price > 100 && p.IsActive)
    .ToListAsync();

// String operations
var laptops = await context.Products
    .Where(p => p.Name.Contains("Laptop"))
    .ToListAsync();
```

## Sorting

Use `OrderBy` and `ThenBy` for sorting; EF Core translates these to ORDER BY in SQL.

```csharp
// Ascending
var byName = await context.Products
    .OrderBy(p => p.Name)
    .ToListAsync();

// Descending
var byPriceDesc = await context.Products
    .OrderByDescending(p => p.Price)
    .ToListAsync();

// Multiple sort criteria
var sorted = await context.Products
    .OrderBy(p => p.Category.Name)
    .ThenByDescending(p => p.Price)
    .ToListAsync();
```

## Pagination

Implement pagination with `Skip` and `Take`; always apply a deterministic order before paging.

```csharp
int page = 1;
int pageSize = 10;

var pagedProducts = await context.Products
    .OrderBy(p => p.Name)
    .Skip((page - 1) * pageSize)
    .Take(pageSize)
    .ToListAsync();

var totalCount = await context.Products.CountAsync();
```

## Projection with Select

Use `Select` to project only the columns you need (more efficient) and to map results to DTOs directly in the query.

```csharp
// Select specific columns (more efficient)
var productNames = await context.Products
    .Select(p => p.Name)
    .ToListAsync();

// Project to DTO
var productDtos = await context.Products
    .Select(p => new ProductDto
    {
        Id = p.Id,
        Name = p.Name,
        Price = p.Price,
        CategoryName = p.Category.Name
    })
    .ToListAsync();

// Anonymous type
var summary = await context.Products
    .Select(p => new { p.Name, p.Price })
    .ToListAsync();
```

## Grouping and Aggregates

Group results for reporting and use aggregate methods (Count, Sum, Average) which translate to SQL aggregates.

```csharp
// Group by category
var byCategory = await context.Products
    .GroupBy(p => p.CategoryId)
    .Select(g => new
    {
        CategoryId = g.Key,
        Count = g.Count(),
        TotalValue = g.Sum(p => p.Price),
        AveragePrice = g.Average(p => p.Price)
    })
    .ToListAsync();

// Aggregates
var maxPrice = await context.Products.MaxAsync(p => p.Price);
var minPrice = await context.Products.MinAsync(p => p.Price);
var count = await context.Products.CountAsync();
var sum = await context.Products.SumAsync(p => p.Stock);
```

## Query vs Method Syntax

Method syntax (fluent LINQ) is most common in EF Core, but query syntax can be useful for complex SQL-like queries—both get translated to SQL.

```csharp
// Method syntax (more common)
var products = await context.Products
    .Where(p => p.Price > 100)
    .OrderBy(p => p.Name)
    .ToListAsync();

// Query syntax (SQL-like)
var products = await (
    from p in context.Products
    where p.Price > 100
    orderby p.Name
    select p
).ToListAsync();
```
