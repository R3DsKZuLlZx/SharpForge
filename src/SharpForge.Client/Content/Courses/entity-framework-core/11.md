## The Concurrency Problem

When two users edit the same record simultaneously, whose changes win? Without handling, the last save overwrites all previous changes.

## Concurrency Tokens

Use concurrency tokens (like `[ConcurrencyCheck]`) to detect when specific properties conflict between updates from different users.

```csharp
public class Product
{
    public int Id { get; set; }
    public string Name { get; set; } = string.Empty;
    public decimal Price { get; set; }
    
    [ConcurrencyCheck]
    public decimal Stock { get; set; }
}

// Fluent API
modelBuilder.Entity<Product>()
    .Property(p => p.Stock)
    .IsConcurrencyToken();
```

## RowVersion (Recommended)

RowVersion (a timestamp/rowversion column) is the recommended approach: the database updates it automatically and EF Core checks it on update to detect conflicts.

```csharp
public class Product
{
    public int Id { get; set; }
    public string Name { get; set; } = string.Empty;
    
    [Timestamp]
    public byte[] RowVersion { get; set; } = null!;
}

// Fluent API
modelBuilder.Entity<Product>()
    .Property(p => p.RowVersion)
    .IsRowVersion();
```

SQL Server automatically updates RowVersion on every change.

## Handling Conflicts

When `DbUpdateConcurrencyException` is thrown, inspect `entry.GetDatabaseValuesAsync()` to decide whether to let the database win, overwrite, merge, or present a UI for the user to resolve.

```csharp
try
{
    await context.SaveChangesAsync();
}
catch (DbUpdateConcurrencyException ex)
{
    foreach (var entry in ex.Entries)
    {
        var proposedValues = entry.CurrentValues;
        var databaseValues = await entry.GetDatabaseValuesAsync();

        if (databaseValues == null)
        {
            // Entity was deleted
            throw new InvalidOperationException("Record was deleted");
        }

        // Option 1: Database wins
        entry.OriginalValues.SetValues(databaseValues);
        
        // Option 2: Client wins
        entry.OriginalValues.SetValues(databaseValues);
        // Keep proposed values, try save again
        
        // Option 3: Merge values
        foreach (var property in proposedValues.Properties)
        {
            var proposedValue = proposedValues[property];
            var databaseValue = databaseValues[property];
            // Custom merge logic here
        }
    }
    
    // Retry save
    await context.SaveChangesAsync();
}
```
