## Implicit Transactions

By default, `SaveChangesAsync` runs inside a transaction so all operations that are part of the save either succeed or fail together.

```csharp
// All operations succeed or fail together
context.Orders.Add(order);
context.OrderItems.AddRange(items);
context.Inventory.Update(inventory);
await context.SaveChangesAsync();  // Single transaction
```

## Explicit Transactions

Use explicit transactions (`BeginTransactionAsync`) when you need multiple SaveChanges calls or to coordinate work that must be atomic and where you need fine-grained commit/rollback control.

```csharp
using var transaction = await context.Database.BeginTransactionAsync();

try
{
    // Operation 1
    var order = new Order { CustomerId = customerId };
    context.Orders.Add(order);
    await context.SaveChangesAsync();

    // Operation 2 (needs order.Id)
    foreach (var item in cartItems)
    {
        context.OrderItems.Add(new OrderItem 
        { 
            OrderId = order.Id, 
            ProductId = item.ProductId 
        });
    }
    await context.SaveChangesAsync();

    // All succeeded - commit
    await transaction.CommitAsync();
}
catch
{
    // Something failed - rollback
    await transaction.RollbackAsync();
    throw;
}
```

## Savepoints

Savepoints allow partial rollback inside a larger transaction—useful when a subset of operations might fail and you want to continue.

```csharp
using var transaction = await context.Database.BeginTransactionAsync();

try
{
    // First batch of changes
    await context.SaveChangesAsync();
    await transaction.CreateSavepointAsync("AfterFirstBatch");

    try
    {
        // Second batch (might fail)
        await context.SaveChangesAsync();
    }
    catch
    {
        // Rollback only to savepoint
        await transaction.RollbackToSavepointAsync("AfterFirstBatch");
    }

    await transaction.CommitAsync();
}
catch
{
    await transaction.RollbackAsync();
    throw;
}
```

## TransactionScope

`TransactionScope` enables ambient transactions that can span multiple DbContext instances or other resource managers; enable async flow and be mindful of distributed transaction implications.

```csharp
using var scope = new TransactionScope(TransactionScopeAsyncFlowOption.Enabled);

// Multiple DbContext operations
using (var context1 = new AppDbContext(options))
{
    await context1.SaveChangesAsync();
}

using (var context2 = new AppDbContext(options))
{
    await context2.SaveChangesAsync();
}

// Commit all
scope.Complete();
```
