## Entity States

Examples of entity states tracked by EF Core: Detached (not tracked), Added, Unchanged, Modified, Deleted — these determine what SaveChanges will do.

```csharp
// Detached - Not tracked by the context
var product = new Product { Name = "Widget" };

// Added - Will be inserted
context.Products.Add(product);  // State = Added

// Unchanged - Loaded from DB, no changes
var loaded = await context.Products.FindAsync(1);  // State = Unchanged

// Modified - Tracked entity with changes
loaded.Price = 99.99m;  // State = Modified

// Deleted - Will be deleted
context.Products.Remove(loaded);  // State = Deleted
```

## Checking Entity State

Use `context.Entry(entity).State` to inspect an entity's tracking state and iterate `entry.Properties` to see which properties changed.

```csharp
var entry = context.Entry(product);
Console.WriteLine(entry.State);  // EntityState enum

// Check modified properties
if (entry.State == EntityState.Modified)
{
    foreach (var prop in entry.Properties)
    {
        if (prop.IsModified)
        {
            Console.WriteLine($"{prop.Metadata.Name}: {prop.OriginalValue} -> {prop.CurrentValue}");
        }
    }
}
```

## No-Tracking Queries

For read-only queries, use `AsNoTracking()` to improve performance because change tracking is skipped.

```csharp
// Read-only queries (better performance)
var products = await context.Products
    .AsNoTracking()
    .ToListAsync();

// Changes won't be detected
products[0].Price = 0;  // Won't be saved!

// Configure globally for read-heavy scenarios
context.ChangeTracker.QueryTrackingBehavior = QueryTrackingBehavior.NoTracking;

// Or in DbContext
protected override void OnConfiguring(DbContextOptionsBuilder options)
{
    options.UseQueryTrackingBehavior(QueryTrackingBehavior.NoTracking);
}
```

## Attaching Entities

Attach disconnected entities when you have DTOs or objects from other tiers; choose Update to mark the whole entity modified or set specific properties as modified to avoid unintended updates.

```csharp
// Attach disconnected entity (State = Unchanged)
context.Products.Attach(product);

// Attach as modified (will update all properties)
context.Products.Update(product);

// Attach and mark specific properties modified
context.Products.Attach(product);
context.Entry(product).Property(p => p.Price).IsModified = true;
```

## ChangeTracker Debugging

Use the ChangeTracker's debug view to inspect what entities are currently tracked — helpful when diagnosing unexpected updates.

```csharp
// View all tracked entities
Console.WriteLine(context.ChangeTracker.DebugView.LongView);

// Count tracked entities
var tracked = context.ChangeTracker.Entries().Count();

// Get pending changes
var added = context.ChangeTracker.Entries()
    .Where(e => e.State == EntityState.Added)
    .ToList();
```
