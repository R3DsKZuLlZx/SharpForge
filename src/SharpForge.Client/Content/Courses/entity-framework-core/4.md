## What Are Migrations?

Migrations are a way to incrementally update your database schema to keep it in sync with your data model while preserving existing data.

## Creating Migrations

Use the CLI `dotnet ef migrations add` to scaffold a migration that captures schema changes; specify project/startup projects when working in multi-project solutions.

```bash
# Create initial migration
dotnet ef migrations add InitialCreate

# Create migration for new changes
dotnet ef migrations add AddProductDescription

# Specify project (if multiple projects)
dotnet ef migrations add AddOrders -p Data -s WebApi
```

## Migration File Structure

This shows an auto-generated migration class: `Up()` applies schema changes and `Down()` reverts them.

```csharp
public partial class AddProductDescription : Migration
{
    protected override void Up(MigrationBuilder migrationBuilder)
    {
        migrationBuilder.AddColumn<string>(
            name: "Description",
            table: "Products",
            type: "nvarchar(500)",
            maxLength: 500,
            nullable: true);
    }

    protected override void Down(MigrationBuilder migrationBuilder)
    {
        migrationBuilder.DropColumn(
            name: "Description",
            table: "Products");
    }
}
```

## Applying Migrations

Apply migrations to the database with `dotnet ef database update`, target a specific migration for rollbacks, or generate SQL scripts for review and production deployments.

```bash
# Apply all pending migrations
dotnet ef database update

# Apply to specific migration
dotnet ef database update AddProductDescription

# Rollback to previous migration
dotnet ef database update InitialCreate

# Generate SQL script instead of applying
dotnet ef migrations script -o migration.sql

# Idempotent script (can run multiple times)
dotnet ef migrations script --idempotent
```

## Managing Migrations

Use the CLI to list or remove migrations during development, and use `context.Database.Migrate()` to apply pending migrations at runtime if needed.

```bash
# List migrations
dotnet ef migrations list

# Remove last migration (if not applied)
dotnet ef migrations remove

# Check for pending migrations in code
if (context.Database.GetPendingMigrations().Any())
{
    context.Database.Migrate();
}
```

## Custom Migration Operations

```csharp
protected override void Up(MigrationBuilder migrationBuilder)
{
    // Add column
    migrationBuilder.AddColumn<string>("Sku", "Products", nullable: true);
    
    // Create index
    migrationBuilder.CreateIndex("IX_Products_Sku", "Products", "Sku");
    
    // Execute raw SQL
    migrationBuilder.Sql("UPDATE Products SET Sku = 'SKU-' + CAST(Id AS VARCHAR)");
    
    // Create stored procedure
    migrationBuilder.Sql(
        "CREATE PROCEDURE GetProductsByCategoryId " +
        "@@CategoryId INT AS BEGIN " +
        "SELECT * FROM Products WHERE CategoryId = @@CategoryId END");
}
```
