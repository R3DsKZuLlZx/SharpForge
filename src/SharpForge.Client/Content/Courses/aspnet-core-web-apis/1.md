## Welcome to ASP.NET Core Web APIs!

In this course, you'll learn how to build production-ready REST APIs using ASP.NET Core. By the end, you'll be able to create secure, scalable, and well-documented APIs that follow best practices.

## What is ASP.NET Core?

ASP.NET Core is a cross-platform, high-performance, open-source framework for building modern, cloud-enabled, Internet-connected applications. It's the successor to ASP.NET and was redesigned from the ground up.

## The Request Pipeline

ASP.NET Core uses a middleware pipeline to handle HTTP requests. Each middleware component can process the request, pass it to the next component, or short-circuit the pipeline.

<div class="pipeline-diagram">
    <div class="pipeline-step">Request</div>
    <div class="pipeline-arrow">→</div>
    <div class="pipeline-step">Logging</div>
    <div class="pipeline-arrow">→</div>
    <div class="pipeline-step">Auth</div>
    <div class="pipeline-arrow">→</div>
    <div class="pipeline-step">Routing</div>
    <div class="pipeline-arrow">→</div>
    <div class="pipeline-step">Endpoint</div>
</div>

The snippet below shows the typical order middleware is registered. Order matters: authentication should run before authorization, and endpoint mapping should be last.

```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

// Middleware is added in order
app.UseHttpsRedirection();   // 1. Redirect HTTP to HTTPS
app.UseAuthentication();     // 2. Who is the user?
app.UseAuthorization();      // 3. Can they access this?
app.MapControllers();        // 4. Route to controller

app.Run();
```

## The Program.cs File

Modern ASP.NET Core uses a simplified Program.cs with top-level statements:

The code below demonstrates the two-phase startup: first register services on the builder, then build the app and configure the middleware pipeline.

```csharp
var builder = WebApplication.CreateBuilder(args);

// Add services to the container
builder.Services.AddControllers();
builder.Services.AddEndpointsApiExplorer();
builder.Services.AddSwaggerGen();

var app = builder.Build();

// Configure the HTTP request pipeline
if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI();
}

app.UseHttpsRedirection();
app.UseAuthorization();
app.MapControllers();

app.Run();
```

### Two Phases

- **Builder phase:** Configure services and dependencies
- **App phase:** Configure the request pipeline (middleware)

The example below shows common RESTful URL patterns and the HTTP methods you should use for each operation.

```bash
# RESTful URL patterns
GET    /api/products         # Get all products
GET    /api/products/5       # Get product with ID 5
POST   /api/products         # Create a new product
PUT    /api/products/5       # Update product 5
DELETE /api/products/5       # Delete product 5
```
