## Making Decisions in Code

Programs need to make decisions based on conditions. Should we show an error message? Is the user logged in? Is the score high enough to pass? In this lesson, you'll learn how to control the flow of your program using conditional statements.


By the end of this lesson, you'll be able to write programs that respond differently based on various conditions.


## The if Statement

The <code>if</code> statement executes code only when a condition is true:


<div class="syntax-box">
<code>if (condition) { // code to execute }</code>
</div>


```csharp
int age = 20;

if (age >= 18)
{
    Console.WriteLine("You are an adult.");
}

// The condition must be a boolean expression
bool isLoggedIn = true;

if (isLoggedIn)
{
    Console.WriteLine("Welcome back!");
}
```

## The if-else Statement

Use <code>else</code> to specify code that runs when the condition is false:



```csharp
int temperature = 25;

if (temperature > 30)
{
    Console.WriteLine("It's hot outside!");
}
else
{
    Console.WriteLine("The weather is pleasant.");
}

// Another example
int score = 45;

if (score >= 50)
{
    Console.WriteLine("You passed!");
}
else
{
    Console.WriteLine("You failed. Try again!");
}
```


## The else-if Chain

Use <code>else if</code> to check multiple conditions in sequence:



```csharp
int score = 85;
string grade;

if (score >= 90)
{
    grade = "A";
}
else if (score >= 80)
{
    grade = "B";
}
else if (score >= 70)
{
    grade = "C";
}
else if (score >= 60)
{
    grade = "D";
}
else
{
    grade = "F";
}

Console.WriteLine($"Your grade is: {grade}");
```

Conditions are evaluated from top to bottom. Once a condition is true, its code runs and the rest are skipped. Order matters!

</div>


```csharp
// Order matters! Put more specific conditions first
int age = 15;

// ❌ Wrong order - the first condition catches everything
if (age >= 0)
{
    Console.WriteLine("Valid age");
}
else if (age >= 18)  // This never runs!
{
    Console.WriteLine("Adult");
}

// ✅ Correct order
if (age >= 18)
{
    Console.WriteLine("Adult");
}
else if (age >= 0)
{
    Console.WriteLine("Valid age, but not an adult");
}
```


## Nested if Statements

You can put if statements inside other if statements:



```csharp
bool hasTicket = true;
int age = 15;

if (hasTicket)
{
    if (age >= 18)
    {
        Console.WriteLine("Welcome to the adult section!");
    }
    else
    {
        Console.WriteLine("Welcome to the general section!");
    }
}
else
{
    Console.WriteLine("Please buy a ticket first.");
}
```

```csharp
// Instead of nested ifs:
if (hasTicket)
{
    if (age >= 18)
    {
        Console.WriteLine("Adult with ticket");
    }
}

// Use logical AND:
if (hasTicket && age >= 18)
{
    Console.WriteLine("Adult with ticket");
}
```


## The switch Statement

When you have many conditions checking the same variable, use <code>switch</code>:



```csharp
int dayNumber = 3;
string dayName;

switch (dayNumber)
{
    case 1:
        dayName = "Monday";
        break;
    case 2:
        dayName = "Tuesday";
        break;
    case 3:
        dayName = "Wednesday";
        break;
    case 4:
        dayName = "Thursday";
        break;
    case 5:
        dayName = "Friday";
        break;
    case 6:
        dayName = "Saturday";
        break;
    case 7:
        dayName = "Sunday";
        break;
    default:
        dayName = "Invalid day";
        break;
}

Console.WriteLine(dayName);  // Wednesday
```



### Key Points About switch- <code>case</code> labels specify values to match- <code>break</code> exits the switch (required in C#)- <code>default</code> handles unmatched values (optional but recommended)- Works with integers, strings, chars, and enums



### Multiple Cases


```csharp
char grade = 'B';

switch (grade)
{
    case 'A':
    case 'B':
        Console.WriteLine("Great job!");
        break;
    case 'C':
        Console.WriteLine("Good effort!");
        break;
    case 'D':
    case 'F':
        Console.WriteLine("Need improvement.");
        break;
    default:
        Console.WriteLine("Invalid grade.");
        break;
}
```


## Switch Expressions (Modern C#)

C# 8+ introduced a more concise **switch expression** syntax:



```csharp
int dayNumber = 3;

// Switch expression - returns a value
string dayName = dayNumber switch
{
    1 => "Monday",
    2 => "Tuesday",
    3 => "Wednesday",
    4 => "Thursday",
    5 => "Friday",
    6 => "Saturday",
    7 => "Sunday",
    _ => "Invalid day"  // _ is the discard pattern (like default)
};

Console.WriteLine(dayName);  // Wednesday
```



### Switch Expressions with Patterns


```csharp
int score = 85;

string grade = score switch
{
    >= 90 => "A",
    >= 80 => "B",
    >= 70 => "C",
    >= 60 => "D",
    _ => "F"
};

// With multiple conditions
string category = score switch
{
    >= 90 and <= 100 => "Excellent",
    >= 70 and < 90 => "Good",
    >= 50 and < 70 => "Average",
    >= 0 and < 50 => "Needs Improvement",
    _ => "Invalid score"
};
```

## Pattern Matching

Modern C# supports powerful pattern matching in conditionals:



### Type Patterns


```csharp
object value = "Hello";

if (value is string text)
{
    Console.WriteLine($"It's a string: {text.ToUpper()}");
}
else if (value is int number)
{
    Console.WriteLine($"It's a number: {number * 2}");
}

// In a switch expression
object data = 42;

string result = data switch
{
    string s => $"String of length {s.Length}",
    int n => $"Integer: {n}",
    null => "Null value",
    _ => "Unknown type"
};
```



### Property Patterns


```csharp
// Check object properties
var person = new { Name = "Alice", Age = 25 };

string message = person switch
{
    { Age: < 18 } => "Minor",
    { Age: >= 18, Age: < 65 } => "Adult",
    { Age: >= 65 } => "Senior",
    _ => "Unknown"
};
```



### Logical Patterns


```csharp
int temperature = 25;

string weather = temperature switch
{
    < 0 => "Freezing",
    >= 0 and < 15 => "Cold",
    >= 15 and < 25 => "Mild",
    >= 25 and < 35 => "Warm",
    >= 35 => "Hot"
};

// Using 'not' pattern
if (value is not null)
{
    Console.WriteLine("Value exists!");
}
```


## Common Mistakes to Avoid


<div class="mistake-box">
<h4>❌ Using = Instead of ==</h4>

```csharp
int x = 5;

// Wrong - this is assignment, not comparison!
if (x = 10)  // Compile error in C#

// Correct
if (x == 10)
```

</div>

<div class="mistake-box">
<h4>❌ Forgetting Braces</h4>

```csharp
// Dangerous - only the first line is in the if
if (isValid)
    Console.WriteLine("Valid");
    DoSomething();  // This ALWAYS runs!

// Safe - use braces
if (isValid)
{
    Console.WriteLine("Valid");
    DoSomething();
}
```

</div>

<div class="mistake-box">
<h4>❌ Comparing Floating-Point Numbers</h4>

```csharp
double a = 0.1 + 0.2;
double b = 0.3;

// Risky - floating-point precision issues
if (a == b)  // Might be false!

// Better - check if they're "close enough"
if (Math.Abs(a - b) < 0.0001)
```

</div>
