## Let's Write Some Code!

In this lesson, you'll create your first C# program from scratch. We'll explore the traditional "Hello, World!" program, understand the structure of C# code, and learn how to build and run your applications.

By the end of this lesson, you'll be comfortable creating new projects and understanding what each part of a C# program does.

## Creating Your First Project

Let's create a new C# console application using the .NET CLI. Open your terminal or command prompt and follow these steps:

### Step 1: Create a New Project

```bash
# Create a new console application
dotnet new console -n HelloWorld

# Navigate into the project folder
cd HelloWorld
```

This command creates a new folder called `HelloWorld` with the following structure:

```bash
HelloWorld/
├── HelloWorld.csproj    # Project configuration file
├── Program.cs           # Your main code file
└── obj/                 # Build artifacts (auto-generated)
```

### Step 2: Open the Project

Open the `HelloWorld` folder in Visual Studio Code:

```bash
# Open in VS Code
code .
```

## Understanding the Generated Code

Open `Program.cs` and you'll see this simple code:

```csharp
// Program.cs (Modern .NET 6+ style)
Console.WriteLine("Hello, World!");
```

Wait, that's it? Just one line? Yes! Modern .NET uses **top-level statements** which remove all the boilerplate code. But let's understand what's happening behind the scenes.

### The Traditional Structure

Before .NET 6, the same program looked like this:

```csharp
using System;

namespace HelloWorld
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello, World!");
        }
    }
}
```

Let's break down each part:

<div class="code-explanation">
    <div class="explanation-item">
        <code>using System;</code>
        <p>Imports the <code>System</code> namespace, giving us access to <code>Console</code> and other fundamental types. In modern .NET, this is automatically included via "implicit usings."</p>
    </div>
    <div class="explanation-item">
        <code>namespace HelloWorld</code>
        <p>A namespace is a container that organizes your code and prevents naming conflicts. Think of it like a folder for your classes.</p>
    </div>
    <div class="explanation-item">
        <code>class Program</code>
        <p>A class is a blueprint for creating objects. Every C# program needs at least one class. <code>Program</code> is the conventional name for the main class.</p>
    </div>
    <div class="explanation-item">
        <code>static void Main(string[] args)</code>
        <p>The <strong>Main</strong> method is the entry point of your application – where execution begins. <code>static</code> means it belongs to the class itself, not an instance. <code>void</code> means it doesn't return a value. <code>string[] args</code> receives command-line arguments.</p>
    </div>
    <div class="explanation-item">
        <code>Console.WriteLine("Hello, World!");</code>
        <p>This line prints text to the console. <code>Console</code> is a class, <code>WriteLine</code> is a method that outputs text followed by a new line.</p>
    </div>
</div>

## Running Your Program

Now let's run the program! In your terminal, make sure you're in the project folder and run:

```bash
dotnet run
```

You should see:

```bash
Hello, World!
```

### What Happened?

When you run `dotnet run`, several things happen:

1. **Compilation:** The C# compiler converts your code into Intermediate Language (IL)
2. **Build:** The IL is packaged into a DLL file
3. **Execution:** The .NET runtime loads and executes your program

## Making It Interactive

Let's modify our program to be more interactive. Update `Program.cs`:

```csharp
// A more interactive Hello World
Console.WriteLine("Welcome to C#!");
Console.WriteLine("==================");

// Ask for the user's name
Console.Write("What is your name? ");
string name = Console.ReadLine();

// Greet the user
Console.WriteLine($"Hello, {name}! Nice to meet you.");
Console.WriteLine("You've just written your first interactive C# program!");
```

Run it again with `dotnet run`:

```bash
Welcome to C#!
==================
What is your name? Alice
Hello, Alice! Nice to meet you.
You've just written your first interactive C# program!
```

### New Concepts Introduced

- `Console.Write()` – Prints text without adding a new line (cursor stays on the same line)
- `Console.ReadLine()` – Waits for the user to type something and press Enter, then returns the text
- `string name` – Declares a variable called `name` that stores text
- `$"Hello, {name}!"` – String interpolation: inserts the value of `name` into the string

## Comments in C#

Comments are notes in your code that the compiler ignores. They help explain what your code does.

```csharp
// This is a single-line comment

/* This is a 
   multi-line comment
   that spans several lines */

/// <summary>
/// This is an XML documentation comment.
/// Used to document classes, methods, etc.
/// </summary>

Console.WriteLine("Comments are ignored by the compiler");
```

## The Project File (.csproj)

Let's take a quick look at the project file. Open `HelloWorld.csproj`:

```xml
<Project Sdk="Microsoft.NET.Sdk">

  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net10.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
  </PropertyGroup>

</Project>
```

Key settings explained:

- `OutputType` – `Exe` means this is an executable program (not a library)
- `TargetFramework` – The .NET version this project uses
- `ImplicitUsings` – Automatically includes common namespaces like `System`
- `Nullable` – Enables nullable reference types (helps prevent null errors)
