## Organizing Code with Methods

As your programs grow, you'll want to organize code into reusable blocks called **methods** (also known as functions). Methods help you avoid repetition, make code easier to read, and simplify debugging.


In this lesson, you'll learn how to create methods, pass data to them, and get results back.


## What is a Method?

A **method** is a named block of code that performs a specific task. You've already been using methods like <code>Console.WriteLine()</code> and <code>Console.ReadLine()</code>.



```csharp
// You've been calling methods all along!
Console.WriteLine("Hello");     // WriteLine is a method
string input = Console.ReadLine();  // ReadLine is a method
int length = input.Length;      // Length is a property (similar concept)
```

## Parameters and Arguments

Parameters let you pass data into a method. Arguments are the actual values you provide when calling the method.



```csharp
// Method with one parameter
void Greet(string name)
{
    Console.WriteLine($"Hello, {name}!");
}

// Calling with arguments
Greet("Alice");   // Output: Hello, Alice!
Greet("Bob");     // Output: Hello, Bob!

// Method with multiple parameters
void DisplayInfo(string name, int age)
{
    Console.WriteLine($"{name} is {age} years old.");
}

DisplayInfo("Alice", 25);  // Output: Alice is 25 years old.
DisplayInfo("Bob", 30);    // Output: Bob is 30 years old.
```

## Return Values

Methods can return a value back to the caller using the <code>return</code> keyword:



```csharp
// Method that returns an int
int Add(int a, int b)
{
    return a + b;
}

// Using the returned value
int sum = Add(5, 3);
Console.WriteLine(sum);  // Output: 8

// Can use directly in expressions
Console.WriteLine(Add(10, 20));  // Output: 30
int result = Add(Add(1, 2), Add(3, 4));  // Nested calls: 3 + 7 = 10
```



```csharp
// Method that returns a string
string GetGreeting(string name)
{
    return $"Hello, {name}!";
}

string message = GetGreeting("Alice");
Console.WriteLine(message);  // Output: Hello, Alice!

// Method that returns a bool
bool IsAdult(int age)
{
    return age >= 18;
}

if (IsAdult(25))
{
    Console.WriteLine("You can vote!");
}
```

```csharp
    if (score >= 90) return "A";
    if (score >= 80) return "B";
    if (score >= 70) return "C";
    if (score >= 60) return "D";
    return "F";
}
```


## Optional Parameters

You can give parameters default values, making them optional:



```csharp
// Parameter with default value
void Greet(string name, string greeting = "Hello")
{
    Console.WriteLine($"{greeting}, {name}!");
}

Greet("Alice");              // Output: Hello, Alice!
Greet("Bob", "Hi");          // Output: Hi, Bob!
Greet("Charlie", "Welcome"); // Output: Welcome, Charlie!

// Multiple optional parameters
void CreateUser(string name, int age = 0, string country = "Unknown")
{
    Console.WriteLine($"Name: {name}, Age: {age}, Country: {country}");
}

CreateUser("Alice");                    // Uses both defaults
CreateUser("Bob", 25);                  // Uses country default
CreateUser("Charlie", 30, "USA");       // No defaults used
```

## Named Arguments

You can specify arguments by name, making code clearer and allowing you to skip optional parameters:



```csharp
void SendEmail(string to, string subject, string body, bool urgent = false)
{
    Console.WriteLine($"To: {to}");
    Console.WriteLine($"Subject: {subject}");
    Console.WriteLine($"Body: {body}");
    Console.WriteLine($"Urgent: {urgent}");
}

// Using named arguments
SendEmail(
    to: "alice@example.com",
    subject: "Meeting",
    body: "See you at 3pm",
    urgent: true
);

// Skip optional parameter, specify later one
SendEmail(
    to: "bob@example.com",
    subject: "Hello",
    body: "Just saying hi"
);

// Mix positional and named (positional must come first)
SendEmail("charlie@example.com", "Test", body: "Testing", urgent: false);
```


## Method Overloading

You can have multiple methods with the same name but different parameters. This is called **overloading**:



```csharp
// Same name, different parameters
int Add(int a, int b)
{
    return a + b;
}

int Add(int a, int b, int c)
{
    return a + b + c;
}

double Add(double a, double b)
{
    return a + b;
}

// C# picks the right one based on arguments
Console.WriteLine(Add(1, 2));        // Calls int Add(int, int) → 3
Console.WriteLine(Add(1, 2, 3));     // Calls int Add(int, int, int) → 6
Console.WriteLine(Add(1.5, 2.5));    // Calls double Add(double, double) → 4.0
```


Real-world example:


```csharp
void Log(string message)
{
    Console.WriteLine($"[INFO] {message}");
}

void Log(string message, string level)
{
    Console.WriteLine($"[{level.ToUpper()}] {message}");
}

void Log(string message, string level, DateTime timestamp)
{
    Console.WriteLine($"[{timestamp:HH:mm:ss}] [{level.ToUpper()}] {message}");
}

Log("Application started");
Log("Connection failed", "error");
Log("User logged in", "info", DateTime.Now);
```


## Expression-Bodied Methods

For simple methods, you can use the <code>=></code> syntax for a more concise form:



```csharp
// Traditional method
int Multiply(int a, int b)
{
    return a * b;
}

// Expression-bodied method (same thing, shorter)
int Multiply(int a, int b) => a * b;

// More examples
bool IsEven(int number) => number % 2 == 0;
string GetFullName(string first, string last) => $"{first} {last}";
void SayHi(string name) => Console.WriteLine($"Hi, {name}!");

// Using them
Console.WriteLine(Multiply(4, 5));     // 20
Console.WriteLine(IsEven(10));         // True
Console.WriteLine(GetFullName("John", "Doe"));  // John Doe
```


## ref and out Parameters

Normally, parameters are passed by value (a copy is made). Use <code>ref</code> and <code>out</code> to pass by reference:



### ref – Pass by Reference


```csharp
void Double(ref int number)
{
    number = number * 2;  // Modifies the original variable
}

int value = 5;
Double(ref value);
Console.WriteLine(value);  // Output: 10 (not 5!)

// Swap example
void Swap(ref int a, ref int b)
{
    int temp = a;
    a = b;
    b = temp;
}

int x = 1, y = 2;
Swap(ref x, ref y);
Console.WriteLine($"x={x}, y={y}");  // x=2, y=1
```



### out – Return Multiple Values


```csharp
// out parameters must be assigned before the method returns
void GetMinMax(int[] numbers, out int min, out int max)
{
    min = numbers.Min();
    max = numbers.Max();
}

int[] data = { 5, 2, 9, 1, 7 };
GetMinMax(data, out int minimum, out int maximum);
Console.WriteLine($"Min: {minimum}, Max: {maximum}");  // Min: 1, Max: 9

// You've seen this pattern with TryParse!
if (int.TryParse("123", out int result))
{
    Console.WriteLine($"Parsed: {result}");
}

// Discard out parameters you don't need with _
if (int.TryParse("456", out _))
{
    Console.WriteLine("It's a valid number");
}
```

## Local Functions

You can define methods inside other methods. These are called **local functions**:



```csharp
void ProcessData(int[] numbers)
{
    // Local function - only accessible within ProcessData
    int CalculateSum()
    {
        int total = 0;
        foreach (int n in numbers)
        {
            total += n;
        }
        return total;
    }

    double CalculateAverage()
    {
        return (double)CalculateSum() / numbers.Length;
    }

    Console.WriteLine($"Sum: {CalculateSum()}");
    Console.WriteLine($"Average: {CalculateAverage():F2}");
}

int[] data = { 10, 20, 30, 40, 50 };
ProcessData(data);
// Output:
// Sum: 150
// Average: 30.00
```
