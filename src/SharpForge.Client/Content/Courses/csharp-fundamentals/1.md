## Welcome to C#!

Welcome to your journey into C# programming! Whether you're completely new to programming or coming from another language, this course will give you a solid foundation in one of the most versatile and powerful programming languages in use today.

In this first lesson, we'll explore what C# is, understand the .NET ecosystem, and get your development environment set up so you're ready to start coding.

## What is C#?

C# (pronounced "C-sharp") is a modern, object-oriented programming language developed by Microsoft. It was created by Anders Hejlsberg and first released in 2000 as part of Microsoft's .NET initiative.

### Key Characteristics of C#

- **Object-Oriented:** Everything in C# revolves around objects and classes, making it easy to model real-world concepts in code.
- **Type-Safe:** C# catches many errors at compile time, before your code even runs, helping you write more reliable software.
- **Modern:** The language is continuously updated with new features that make coding more efficient and expressive.
- **Cross-Platform:** With .NET, your C# code can run on Windows, macOS, Linux, and even mobile devices.
- **Versatile:** Build web applications, desktop apps, mobile apps, games, cloud services, and more.

## What is .NET?

.NET (pronounced "dot net") is a free, open-source development platform created by Microsoft. Think of it as the foundation that powers your C# applications.

### The .NET Ecosystem

.NET provides everything you need to build applications:

### .NET Versions

You might hear about different versions of .NET:

- **.NET Framework:** The original Windows-only version (legacy).
- **.NET Core:** The cross-platform rewrite (versions 1.0-3.1).
- **.NET 5+:** The unified platform going forward. We use .NET 10 in this course.

## Your First Look at C# Code

Let's take a sneak peek at what C# code looks like. Don't worry about understanding everything yet – we'll cover each concept in detail in upcoming lessons.

```csharp
// This is a simple C# program
using System;

class Program
{
    static void Main()
    {
        // Print a greeting to the console
        Console.WriteLine("Hello, future C# developer!");
        
        // Ask for the user's name
        Console.Write("What's your name? ");
        string name = Console.ReadLine();
        
        // Greet the user
        Console.WriteLine($"Nice to meet you, {name}!");
    }
}
```

Let's briefly look at what's happening:

- `using System;` – Imports functionality we need
- `class Program` – Defines a container for our code
- `static void Main()` – The entry point where our program starts
- `Console.WriteLine()` – Displays text on the screen
- `string name` – Creates a variable to store text
- `$"..."` – String interpolation (inserting variables into text)
