## Storing Data in Your Programs

Every program needs to work with data – names, numbers, dates, and more. In this lesson, you'll learn how to store and manage data using **variables** and understand the different **data types** that C# provides.

By the end of this lesson, you'll be able to declare variables, choose the right data type for your needs, and convert between different types.

## What is a Variable?

A **variable** is a named container that stores a value in your computer's memory. Think of it like a labeled box where you can put something, take it out, or replace it with something else.

```csharp
// Declaring and assigning a variable
string name = "Alice";
int age = 25;
double salary = 55000.50;
bool isEmployed = true;
```

### Variable Declaration Syntax

The basic syntax for declaring a variable is:

<div class="syntax-box">
    <code>type variableName = value;</code>
</div>

- **type** – The kind of data the variable will hold (e.g., `int`, `string`)
- **variableName** – The name you give to the variable
- **value** – The initial value (optional at declaration)

```csharp
// You can also declare first, assign later
int score;          // Declaration
score = 100;        // Assignment

// Or declare multiple variables of the same type
int x, y, z;
x = 10;
y = 20;
z = 30;

// Or initialize multiple at once
int a = 1, b = 2, c = 3;
```

## Naming Variables

Choosing good variable names makes your code easier to read and understand. Follow these rules and conventions:

### Rules (Must Follow)

- Must start with a letter or underscore (`_`)
- Can contain letters, numbers, and underscores
- Cannot be a C# keyword (like `class`, `int`, `if`)
- Case-sensitive (`Name` and `name` are different)

### Conventions (Best Practices)

- Use **camelCase** for local variables: `firstName`, `totalAmount`
- Use meaningful, descriptive names
- Avoid single letters except for loop counters
- Don't use abbreviations that aren't widely known

```csharp
// ✅ Good variable names
string firstName = "John";
int itemCount = 42;
double accountBalance = 1234.56;
bool isLoggedIn = true;

// ❌ Poor variable names
string s = "John";           // Too short, unclear
int x = 42;                  // What does x represent?
double aB = 1234.56;         // Cryptic abbreviation
bool flag = true;            // Flag for what?
```

### Text Types

```csharp
// char - a single character (use single quotes)
char grade = 'A';
char symbol = '@';
char newline = '\n';

// string - text of any length (use double quotes)
string greeting = "Hello, World!";
string empty = "";
string name = "Alice";

// String with special characters (escape sequences)
string path = "C:\\Users\\Documents";      // Backslash
string quote = "She said \"Hello\"";       // Quotes
string multiline = "Line 1\nLine 2";       // New line

// Verbatim string (@) - no escaping needed
string verbatimPath = @"C:\Users\Documents";

// Raw string literals (C# 11+) - for complex strings
string json = """
    {
        "name": "Alice",
        "age": 25
    }
    """;
```

### Boolean Type

```csharp
// bool - true or false
bool isActive = true;
bool hasPermission = false;
bool isComplete = true;

// Often used with comparisons
bool isAdult = age >= 18;
bool isEmpty = name.Length == 0;
```

## The var Keyword

C# can often figure out the type automatically using **type inference**:

```csharp
// Explicit typing
string message = "Hello";
int count = 42;
double price = 19.99;

// Implicit typing with var
var message = "Hello";      // Compiler knows it's a string
var count = 42;             // Compiler knows it's an int
var price = 19.99;          // Compiler knows it's a double

// var requires initialization
var x;          // ❌ Error! Can't infer type without a value
var y = 10;     // ✅ OK
```

## Constants

A **constant** is a variable whose value cannot change after it's set:

```csharp
// Constants - use 'const' keyword
const double Pi = 3.14159265359;
const int MaxRetries = 3;
const string AppName = "MyApplication";

// Trying to change a constant causes an error
Pi = 3.14;  // ❌ Error! Cannot assign to a constant

// Convention: Use PascalCase for constants
```

Use constants for values that never change, like mathematical constants, configuration values, or magic numbers that have meaning.

## Nullable Types

Sometimes a variable might not have a value. C# handles this with **nullable types**:

```csharp
// Regular types cannot be null
int age = null;        // ❌ Error!
string name = null;    // ⚠️ Warning (with nullable enabled)

// Nullable value types - add ? after the type
int? age = null;       // ✅ OK - age might not have a value
int? score = 85;       // ✅ OK - score has a value

// Check if nullable has a value
if (age.HasValue)
{
    Console.WriteLine($"Age is {age.Value}");
}
else
{
    Console.WriteLine("Age is unknown");
}

// Null-coalescing operator (??) - provide a default
int displayAge = age ?? 0;  // Use 0 if age is null

// Nullable reference types (string?)
string? middleName = null;  // Explicitly nullable string
```

## Type Conversion

Sometimes you need to convert between different types:

### Implicit Conversion (Automatic)

When there's no risk of data loss, C# converts automatically:

```csharp
int myInt = 100;
long myLong = myInt;      // int to long - OK (long is bigger)
double myDouble = myInt;  // int to double - OK

// Small to large: byte → short → int → long → float → double
```

### Explicit Conversion (Casting)

When data might be lost, you must explicitly cast:

```csharp
double myDouble = 9.78;
int myInt = (int)myDouble;    // Cast to int - loses decimal part
Console.WriteLine(myInt);      // Output: 9

long bigNumber = 1000;
int smallNumber = (int)bigNumber;  // Might overflow if too large!
```

### Converting To and From Strings

```csharp
// Converting TO string - use ToString()
int number = 42;
string text = number.ToString();    // "42"

double price = 19.99;
string priceText = price.ToString("C");  // "$19.99" (currency format)

// Converting FROM string - use Parse() or TryParse()
string input = "123";
int value = int.Parse(input);       // Throws if invalid!

// Safer: TryParse returns true/false
string userInput = "456";
if (int.TryParse(userInput, out int result))
{
    Console.WriteLine($"Parsed: {result}");
}
else
{
    Console.WriteLine("Invalid number");
}

// Convert class - another option
int num = Convert.ToInt32("789");
double dbl = Convert.ToDouble("3.14");
```

## Default Values

Every type has a default value when not explicitly initialized:

<div class="type-table">
    <div class="type-row header">
        <span>Type</span>
        <span>Default Value</span>
    </div>
    <div class="type-row">
        <span>Numeric types (int, double, etc.)</span>
        <code>0</code>
    </div>
    <div class="type-row">
        <span>bool</span>
        <code>false</code>
    </div>
    <div class="type-row">
        <span>char</span>
        <code>'\0'</code> (null character)
    </div>
    <div class="type-row">
        <span>Reference types (string, object)</span>
        <code>null</code>
    </div>
</div>

```csharp
// Using the default keyword
int number = default;      // 0
bool flag = default;       // false
string text = default;     // null

// Or with the type specified
var x = default(int);      // 0
```
