## OnInitialized / OnInitializedAsync

This example demonstrates lifecycle methods used to initialize a component. Use `OnInitializedAsync` for asynchronous initial work (e.g., loading data). Use `IDisposable` to release resources like timers or event subscriptions.

```csharp
@@code {
    private List<Product>? products;

    // Called once when component is first created
    protected override void OnInitialized()
    {
        // Synchronous initialization
    }

    protected override async Task OnInitializedAsync()
    {
        // Async initialization - load data
        products = await Http.GetFromJsonAsync<List<Product>>("api/products");
    }
}
```

## OnParametersSet / OnParametersSetAsync

Use `OnParametersSetAsync` to react to changes in component parameters (e.g., reloading data when an input parameter changes).

```csharp
@@code {
    [Parameter]
    public int ProductId { get; set; }

    private Product? product;

    // Called when parameters change
    protected override async Task OnParametersSetAsync()
    {
        // Reload data when ProductId changes
        product = await Http.GetFromJsonAsync<Product>($"api/products/{ProductId}");
    }
}
```

## OnAfterRender / OnAfterRenderAsync

`OnAfterRenderAsync` runs after the component has rendered; check the `firstRender` flag for one-time initialization that needs the DOM (e.g., JS interop or focusing an element).

```csharp
@@code {
    private ElementReference inputElement;

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender)
        {
            // DOM is now available - only runs once
            await inputElement.FocusAsync();
            await JSRuntime.InvokeVoidAsync("initializeChart", chartElement);
        }
    }
}
```

## ShouldRender

Override `ShouldRender` to prevent unnecessary re-renders when state updates but UI doesn't need to change; return false to skip rendering.

```csharp
@@code {
    private bool shouldRender = true;

    protected override bool ShouldRender()
    {
        // Return false to skip rendering
        return shouldRender;
    }
}
```

## IDisposable - Cleanup

Implement `IDisposable` (or `IAsyncDisposable`) to clean up timers, event handlers, or other unmanaged resources to avoid leaks.

```csharp
@@implements IDisposable

@@code {
    private Timer? timer;

    protected override void OnInitialized()
    {
        timer = new Timer(_ => InvokeAsync(StateHasChanged), null, 0, 1000);
    }

    public void Dispose()
    {
        timer?.Dispose();
    }
}

@@* For async disposal *@@
@@implements IAsyncDisposable

@@code {
    public async ValueTask DisposeAsync()
    {
        await SomeAsyncCleanup();
    }
}
```

## StateHasChanged

Call `StateHasChanged` when you need to force a re-render (for example, after external events or timers); use `InvokeAsync` when called from non-UI threads.

```csharp
@@code {
    private int count = 0;

    private void HandleExternalEvent()
    {
        count++;
        StateHasChanged(); // Tell Blazor to re-render
    }

    // For async callbacks from non-UI threads
    private async void OnTimerElapsed()
    {
        count++;
        await InvokeAsync(StateHasChanged);
    }
}
```
