## HttpClient Setup

This section shows configuring `HttpClient` for API calls and performing common HTTP operations (GET/POST/PUT/DELETE). It also illustrates basic error handling patterns you'll commonly need in a Blazor app.

```csharp
// Program.cs - already configured in template
builder.Services.AddScoped(sp => 
    new HttpClient { BaseAddress = new Uri(builder.HostEnvironment.BaseAddress) });

// Or with typed client
builder.Services.AddHttpClient<IProductService, ProductService>(client =>
    client.BaseAddress = new Uri("https://api.example.com"));
```

## GET Requests

This example shows using `HttpClient.GetFromJsonAsync` to load data during `OnInitializedAsync` and render it in markup with conditional loading state.

```razor
@@inject HttpClient Http

@@if (products == null)
{
    <p>Loading...</p>
}
else
{
    @@foreach (var product in products)
    {
        <div>@@product.Name - @@product.Price.ToString("C")</div>
    }
}

@@code {
    private List<Product>? products;

    protected override async Task OnInitializedAsync()
    {
        products = await Http.GetFromJsonAsync<List<Product>>("api/products");
    }
}
```

## POST Requests

Use `PostAsJsonAsync` to send an object as JSON; check the response and read the created resource if the API returns it.

```csharp
private async Task CreateProduct()
{
    var newProduct = new Product { Name = "Widget", Price = 9.99m };
    
    var response = await Http.PostAsJsonAsync("api/products", newProduct);
    
    if (response.IsSuccessStatusCode)
    {
        var created = await response.Content.ReadFromJsonAsync<Product>();
        products?.Add(created!);
    }
}
```

## PUT and DELETE

Examples for update and delete operations using `PutAsJsonAsync` and `DeleteAsync`, including simple success checks.

```csharp
// UPDATE
private async Task UpdateProduct(Product product)
{
    var response = await Http.PutAsJsonAsync($"api/products/{product.Id}", product);
    response.EnsureSuccessStatusCode();
}

// DELETE
private async Task DeleteProduct(int id)
{
    var response = await Http.DeleteAsync($"api/products/{id}");
    if (response.IsSuccessStatusCode)
    {
        products?.RemoveAll(p => p.Id == id);
    }
}
```

## Error Handling

Show patterns for try/catch and manual status-code checks. Prefer friendly error messages and centralized logging in services.

```csharp
private string? errorMessage;

private async Task LoadProducts()
{
    try
    {
        products = await Http.GetFromJsonAsync<List<Product>>("api/products");
    }
    catch (HttpRequestException ex)
    {
        errorMessage = $"Error loading products: {ex.Message}";
    }
}

// Or check status codes
private async Task LoadProductSafe()
{
    var response = await Http.GetAsync("api/products");
    
    if (response.IsSuccessStatusCode)
    {
        products = await response.Content.ReadFromJsonAsync<List<Product>>();
    }
    else if (response.StatusCode == HttpStatusCode.NotFound)
    {
        products = new List<Product>();
    }
    else
    {
        errorMessage = $"Error: {response.StatusCode}";
    }
}
```

## Creating a Service

Wrap API calls in a typed service to centralize HTTP concerns (base URLs, headers, retries) and make testing easier.

```csharp
public class ProductService
{
    private readonly HttpClient _http;
    
    public ProductService(HttpClient http) => _http = http;

    public async Task<List<Product>> GetAllAsync()
        => await _http.GetFromJsonAsync<List<Product>>("api/products") ?? new();

    public async Task<Product?> GetByIdAsync(int id)
        => await _http.GetFromJsonAsync<Product>($"api/products/{id}");

    public async Task<Product> CreateAsync(Product product)
    {
        var response = await _http.PostAsJsonAsync("api/products", product);
        return await response.Content.ReadFromJsonAsync<Product>() ?? product;
    }
}

// Register: builder.Services.AddScoped<ProductService>();
```
