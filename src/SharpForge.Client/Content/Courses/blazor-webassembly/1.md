## Welcome to Blazor!

Blazor is a framework for building interactive web UIs using C# instead of JavaScript. You can create rich, interactive web applications while leveraging your existing .NET skills and sharing code between client and server.

## What is Blazor?

Blazor lets you build interactive web UIs using C# and .NET. The name "Blazor" comes from "Browser" + "Razor" (the .NET view engine).

## How Blazor WebAssembly Works

When a user visits your Blazor WebAssembly app:

1. Browser downloads the HTML page
2. Downloads the Blazor JavaScript file
3. Downloads the .NET runtime (as WebAssembly)
4. Downloads your app's DLLs
5. .NET code runs directly in the browser

```html
<!-- The magic starts here -->
<script src="_framework/blazor.webassembly.js"></script>
```

## When to Use Blazor WebAssembly

Blazor WebAssembly is ideal for:

- Progressive Web Apps (PWAs)
- Apps that need offline support
- Static site hosting (GitHub Pages, Azure Static Web Apps)
- Single-page applications
- When you want to share C# code with your backend

## Your First Look at a Blazor Component

This example shows a minimal Blazor component: a route declaration, markup, a bound expression, an event handler, and a local @@code block that holds component state and logic. Copy it into a `.razor` file and navigate to the route to see it run in the browser.

```razor
@@page "/counter"

<h1>Counter</h1>

<p>Current count: @@currentCount</p>

<button class="btn btn-primary" @@onclick="IncrementCount">
    Click me
</button>

@@code {
    private int currentCount = 0;

    private void IncrementCount()
    {
        currentCount++;
    }
}
```

This is a complete Blazor component! It combines HTML markup with C# code in a single `.razor` file.
