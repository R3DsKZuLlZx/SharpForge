## One-Way Binding

These examples show one-way and two-way binding in Blazor using `@@bind` and the built-in input components (InputText, InputNumber, InputDate). They illustrate how values flow between UI and component state.

```razor
@@* Display a value (one-way) *@@
<p>Hello, @@name!</p>
<input value="@@name" />

@@* Attribute binding *@@
<button disabled="@@isDisabled">Submit</button>
<div class="@@cssClass">Styled div</div>

@@code {
    private string name = "World";
    private bool isDisabled = false;
    private string cssClass = "highlight";
}
```

## Two-Way Binding with @@bind

```razor
@@* Two-way binding *@@
<input @@bind="name" />
<p>You entered: @@name</p>

@@* Different input types *@@
<input type="text" @@bind="textValue" />
<input type="number" @@bind="numberValue" />
<input type="checkbox" @@bind="isChecked" />
<input type="date" @@bind="dateValue" />

<select @@bind="selectedOption">
    <option value="a">Option A</option>
    <option value="b">Option B</option>
</select>

<textarea @@bind="textArea"></textarea>

@@code {
    private string name = "";
    private string textValue = "";
    private int numberValue = 0;
    private bool isChecked = false;
    private DateTime dateValue = DateTime.Today;
    private string selectedOption = "a";
    private string textArea = "";
}
```

## Binding Events

```razor
@@* Default: onchange (when focus leaves) *@@
<input @@bind="search" />

@@* Bind on input (real-time) *@@
<input @@bind="search" @@bind:event="oninput" />

@@* With callback after binding *@@
<input @@bind="search" @@bind:after="SearchAsync" />

@@code {
    private string search = "";
    
    private async Task SearchAsync()
    {
        // Called after search is updated
        await PerformSearch(search);
    }
}
```

## Binding with Format

```razor
@@* Date formatting *@@
<input @@bind="startDate" @@bind:format="yyyy-MM-dd" />

@@* Custom format for display *@@
<p>Price: @@price.ToString("C2")</p>

@@code {
    private DateTime startDate = DateTime.Today;
    private decimal price = 19.99m;
}
```

## Component Two-Way Binding

```razor
@@* Counter.razor - child component *@@
<button @@onclick="Decrement">-</button>
<span>@@Value</span>
<button @@onclick="Increment">+</button>

@@code {
    [Parameter]
    public int Value { get; set; }

    [Parameter]
    public EventCallback<int> ValueChanged { get; set; }

    private async Task Increment() => await ValueChanged.InvokeAsync(Value + 1);
    private async Task Decrement() => await ValueChanged.InvokeAsync(Value - 1);
}

@@* Parent usage with @@bind *@@
<Counter @@bind-Value="quantity" />
<p>Quantity: @@quantity</p>

@@code {
    private int quantity = 1;
}
```
