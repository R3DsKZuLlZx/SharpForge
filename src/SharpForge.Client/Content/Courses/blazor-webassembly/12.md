## When to Use JS Interop

- Access browser APIs (localStorage, geolocation, clipboard)
- Use existing JavaScript libraries (charts, maps, editors)
- Manipulate the DOM directly (focus, scroll, animations)
- Access features not yet available in Blazor

## Calling JavaScript from C#

The first snippet is a sample JavaScript file with small helper functions you can call from C# via JS interop.

```javascript
// wwwroot/js/interop.js
window.showAlert = (message) => {
    alert(message);
};

window.getWindowWidth = () => {
    return window.innerWidth;
};

window.focusElement = (element) => {
    element.focus();
};
```

Add the script to your host page so it's available to the runtime at startup.

```html
<!-- Add to index.html -->
<script src="js/interop.js"></script>
```

## IJSRuntime

This example demonstrates using `IJSRuntime` in a component to call those helper functions and to receive return values.

```razor
@@inject IJSRuntime JS

<button @@onclick="ShowAlert">Show Alert</button>
<button @@onclick="GetWidth">Get Window Width</button>
<p>Width: @@width</p>

@@code {
    private int width;

    private async Task ShowAlert()
    {
        await JS.InvokeVoidAsync("showAlert", "Hello from Blazor!");
    }

    private async Task GetWidth()
    {
        width = await JS.InvokeAsync<int>("getWindowWidth");
    }
}
```

## Element References

Use an `ElementReference` to pass a DOM element from Blazor to JS so the JS function can act on that element.

```razor
<input @@ref="inputElement" />
<button @@onclick="FocusInput">Focus Input</button>

@@code {
    private ElementReference inputElement;

    private async Task FocusInput()
    {
        await JS.InvokeVoidAsync("focusElement", inputElement);
        // Or use built-in:
        await inputElement.FocusAsync();
    }
}
```

## Calling C# from JavaScript

The C# snippets below show how to expose static and instance methods to JavaScript using `[JSInvokable]`.

```csharp
// Static method
[JSInvokable]
public static string GetGreeting(string name)
{
    return $"Hello, {name}!";
}

// Instance method
[JSInvokable]
public void UpdateCounter(int value)
{
    counter = value;
    StateHasChanged();
}
```

On the JS side, call the static and instance methods using the runtime helpers shown below.

```javascript
// Call static method
const greeting = await DotNet.invokeMethodAsync(
    'MyBlazorApp',  // Assembly name
    'GetGreeting',
    'World'
);

// Call instance method (requires reference)
dotNetReference.invokeMethodAsync('UpdateCounter', 42);
```

## Passing .NET Reference to JS

This example shows creating a `DotNetObjectReference` for the component so JavaScript can call instance methods (and demonstrates disposing it when the component is destroyed).

```razor
@@code {
    private DotNetObjectReference<MyComponent>? dotNetRef;

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender)
        {
            dotNetRef = DotNetObjectReference.Create(this);
            await JS.InvokeVoidAsync("registerCallback", dotNetRef);
        }
    }

    [JSInvokable]
    public void OnJsCallback(string data)
    {
        // Called from JavaScript
    }

    public void Dispose()
    {
        dotNetRef?.Dispose();
    }
}
```
