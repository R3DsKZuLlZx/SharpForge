## EditForm Basics

This snippet demonstrates `EditForm` with `DataAnnotationsValidator` to perform model-based validation, plus Input components and `ValidationMessage` for per-field errors. Use this pattern for server/client validation integration.

```razor
<EditForm Model="@@product" OnValidSubmit="HandleSubmit">
    <DataAnnotationsValidator />
    <ValidationSummary />

    <div class="form-group">
        <label>Name</label>
        <InputText @@bind-Value="product.Name" class="form-control" />
        <ValidationMessage For="() => product.Name" />
    </div>

    <button type="submit" class="btn btn-primary">Save</button>
</EditForm>

@@code {
    private Product product = new();

    private async Task HandleSubmit()
    {
        await Http.PostAsJsonAsync("api/products", product);
    }
}
```

## Model with Validation

This model shows how to use DataAnnotation attributes to declare validation rules directly on properties which are used by `EditForm` and server-side model binding.

```csharp
public class Product
{
    [Required(ErrorMessage = "Name is required")]
    [StringLength(100, MinimumLength = 2)]
    public string Name { get; set; } = "";

    [Required]
    [Range(0.01, 999999.99, ErrorMessage = "Price must be positive")]
    public decimal Price { get; set; }

    [EmailAddress]
    public string? ContactEmail { get; set; }

    [Url]
    public string? Website { get; set; }
}
```

## Input Components

Use Blazor's built-in `Input*` components for typed input binding and validation integration; they work with `EditForm` and show validation state.

```razor
@@* Text input *@@
<InputText @@bind-Value="model.Name" />

@@* Number input *@@
<InputNumber @@bind-Value="model.Price" />

@@* Checkbox *@@
<InputCheckbox @@bind-Value="model.IsActive" />

@@* Date *@@
<InputDate @@bind-Value="model.StartDate" />

@@* Select/Dropdown *@@
<InputSelect @@bind-Value="model.Category">
    <option value="">Select...</option>
    <option value="electronics">Electronics</option>
    <option value="clothing">Clothing</option>
</InputSelect>

@@* Text area *@@
<InputTextArea @@bind-Value="model.Description" />

@@* Radio buttons *@@
<InputRadioGroup @@bind-Value="model.Priority">
    <InputRadio Value="@@("low")" /> Low
    <InputRadio Value="@@("medium")" /> Medium
    <InputRadio Value="@@("high")" /> High
</InputRadioGroup>
```

## Form Events

The snippets below show the different `EditForm` callbacks: `OnValidSubmit`, `OnInvalidSubmit`, and `OnSubmit` so you can handle submission according to validation state.

```razor
@@* OnValidSubmit - fires only if validation passes *@@
<EditForm Model="@@model" OnValidSubmit="HandleValid">

@@* OnInvalidSubmit - fires if validation fails *@@
<EditForm Model="@@model" OnInvalidSubmit="HandleInvalid">

@@* OnSubmit - fires always, you check validity *@@
<EditForm Model="@@model" OnSubmit="HandleSubmit">

@@code {
    private void HandleSubmit(EditContext context)
    {
        if (context.Validate())
        {
            // Valid - save
        }
        else
        {
            // Invalid - show errors
        }
    }
}
```

## Custom Validation

Create a custom `ValidationAttribute` for reusable, declarative checks that integrate with DataAnnotations-based validation.

```csharp
public class FutureDateAttribute : ValidationAttribute
{
    protected override ValidationResult? IsValid(
        object? value, ValidationContext context)
    {
        if (value is DateTime date && date <= DateTime.Now)
        {
            return new ValidationResult("Date must be in the future");
        }
        return ValidationResult.Success;
    }
}
```

## Displaying Validation Errors

Use `ValidationSummary` for top-level errors and `ValidationMessage` for per-field messaging; combine with CSS for custom styling.

```razor
@@* Show all errors at top *@@
<ValidationSummary />

@@* Show error for specific field *@@
<ValidationMessage For="() => model.Name" />

@@* Custom error styling *@@
<InputText @@bind-Value="model.Name" class="form-control" />
<ValidationMessage For="() => model.Name" class="text-danger" />
```
