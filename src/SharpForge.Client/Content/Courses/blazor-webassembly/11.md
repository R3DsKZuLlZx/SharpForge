## State Management Options

- **Component state:** Local to a single component
- **Cascading values:** Pass state down the component tree
- **Scoped services:** Share state via DI
- **Browser storage:** Persist state in localStorage/sessionStorage

## State Container Service

This code shows a simple state container providing methods to mutate state and an `OnChange` event so components can subscribe to updates.

```csharp
// Services/AppState.cs
public class AppState
{
    public string? CurrentUser { get; private set; }
    public List<CartItem> CartItems { get; } = new();

    public event Action? OnChange;

    public void SetUser(string user)
    {
        CurrentUser = user;
        NotifyStateChanged();
    }

    public void AddToCart(Product product)
    {
        CartItems.Add(new CartItem { Product = product, Quantity = 1 });
        NotifyStateChanged();
    }

    private void NotifyStateChanged() => OnChange?.Invoke();
}

// Register as singleton (persists for app lifetime)
builder.Services.AddSingleton<AppState>();
```

## Using State in Components

The snippet below shows injecting the state service into a component and subscribing to `OnChange` to call `StateHasChanged` when state updates.

```razor
@@inject AppState State
@@implements IDisposable

<p>Cart has @@State.CartItems.Count items</p>

@@code {
    protected override void OnInitialized()
    {
        State.OnChange += StateHasChanged;
    }

    public void Dispose()
    {
        State.OnChange -= StateHasChanged;
    }
}
```

## Browser Storage

Install and register a local storage package to persist small pieces of client-side state.

```bash
dotnet add package Blazored.LocalStorage
```

Register the service in `Program.cs` so it is available via DI.

```csharp
// Program.cs
builder.Services.AddBlazoredLocalStorage();
```

Example usage inside a component to load and save values.

```razor
@@inject Blazored.LocalStorage.ILocalStorageService LocalStorage

@@code {
    protected override async Task OnInitializedAsync()
    {
        // Load from storage
        var theme = await LocalStorage.GetItemAsync<string>("theme");
    }

    private async Task SaveTheme(string theme)
    {
        await LocalStorage.SetItemAsync("theme", theme);
    }

    private async Task ClearTheme()
    {
        await LocalStorage.RemoveItemAsync("theme");
    }
}
```

## Cascading State

```razor
@@* App.razor or MainLayout.razor *@@
<CascadingValue Value="@@appState">
    @@Body
</CascadingValue>

@@code {
    private AppState appState = new();
}

@@* Any child component *@@
@@code {
    [CascadingParameter]
    public AppState? State { get; set; }
}
```

## URL-Based State

```razor
@@page "/products"
@@inject NavigationManager Nav

@@* State in query string *@@
@@code {
    [SupplyParameterFromQuery]
    public string? Category { get; set; }

    [SupplyParameterFromQuery]
    public int Page { get; set; } = 1;

    private void ChangePage(int page)
    {
        Nav.NavigateTo($"/products?category={Category}&page={page}");
    }
}
```
