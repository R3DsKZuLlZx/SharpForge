## What is a Task?

Tasks represent asynchronous operations; a `Task` doesn't return a value, while `Task<T>` does - await them to get results.

```csharp
// Task - no return value
Task task = DoSomethingAsync();

// Task<T> - returns a value
Task<string> taskWithResult = GetDataAsync();
string result = await taskWithResult;
```

## Task States

Inspect task state and status properties to diagnose or monitor task lifecycle (running, completed, faulted, canceled).

```csharp
var task = DoWorkAsync();

Console.WriteLine(task.Status);        // Running, WaitingForActivation, etc.
Console.WriteLine(task.IsCompleted);   // true when finished (success, fault, or cancel)
Console.WriteLine(task.IsCompletedSuccessfully);  // true only on success
Console.WriteLine(task.IsFaulted);     // true if exception thrown
Console.WriteLine(task.IsCanceled);    // true if canceled
```

## Creating Tasks

Different ways to create tasks: completed tasks, Task.Run for CPU-bound work, and wrapping async lambdas for background operations.

```csharp
// 1. Return completed task
Task<int> completed = Task.FromResult(42);

// 2. Return completed Task (no value)
Task done = Task.CompletedTask;

// 3. Run CPU-bound work on thread pool
Task cpuWork = Task.Run(() => 
{
    // CPU-intensive work here
    return ComputeValue();
});

// 4. Create from async lambda
Task asyncWork = Task.Run(async () =>
{
    await Task.Delay(100);
    return "result";
});
```
