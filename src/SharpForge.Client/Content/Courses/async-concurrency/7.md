## IProgress&lt;T&gt; Interface

Show how to report progress from a library method by accepting an optional `IProgress<int>` and calling `Report` to notify callers.

```csharp
// Method that reports progress
public async Task ProcessFilesAsync(
    IEnumerable<string> files,
    IProgress<int>? progress = null,
    CancellationToken ct = default)
{
    var fileList = files.ToList();
    for (int i = 0; i < fileList.Count; i++)
    {
        ct.ThrowIfCancellationRequested();
        
        await ProcessFileAsync(fileList[i], ct);
        
        // Report progress (percentage)
        progress?.Report((i + 1) * 100 / fileList.Count);
    }
}
```

## Progress&lt;T&gt; Class

In UI code, use `Progress<T>` which captures the synchronization context and invokes callbacks on the UI thread safely.

```csharp
// In UI code
var progress = new Progress<int>(percent =>
{
    progressBar.Value = percent;
    statusLabel.Text = $"Processing: {percent}%";
});

await ProcessFilesAsync(files, progress, cts.Token);
```

## Custom Progress Data

Create a progress record type to include richer information (filename, bytes, percent) and report it from download loops to update UI progressively.

```csharp
public record DownloadProgress(
    string FileName,
    long BytesDownloaded,
    long TotalBytes,
    int PercentComplete);

public async Task DownloadAsync(
    string url,
    IProgress<DownloadProgress>? progress = null)
{
    var response = await httpClient.GetAsync(url, HttpCompletionOption.ResponseHeadersRead);
    var totalBytes = response.Content.Headers.ContentLength ?? -1;
    
    await using var stream = await response.Content.ReadAsStreamAsync();
    var buffer = new byte[8192];
    long bytesRead = 0;
    int read;
    
    while ((read = await stream.ReadAsync(buffer)) > 0)
    {
        bytesRead += read;
        
        progress?.Report(new DownloadProgress(
            Path.GetFileName(url),
            bytesRead,
            totalBytes,
            (int)(bytesRead * 100 / totalBytes)));
    }
}
```
