## lock Statement

Use `lock` for simple mutual exclusion; avoid locking on public objects or `this` to prevent deadlocks.

```csharp
private readonly object _lock = new();
private int _counter;

public void Increment()
{
    lock (_lock)
    {
        _counter++;  // Only one thread at a time
    }
}

// ❌ DON'T lock on 'this' or public objects
lock (this) { }  // Bad!
lock (typeof(MyClass)) { }  // Bad!
```

## SemaphoreSlim

`SemaphoreSlim` is async-friendly for throttling concurrent access; always release the semaphore in a finally block.

```csharp
// Limit concurrent access
private readonly SemaphoreSlim _semaphore = new(initialCount: 3);

public async Task ProcessAsync()
{
    await _semaphore.WaitAsync();  // Async-friendly!
    try
    {
        await DoWorkAsync();
    }
    finally
    {
        _semaphore.Release();
    }
}
```

## ReaderWriterLockSlim

Reader-writer locks allow multiple concurrent readers or a single writer; useful for caches with many readers and fewer writers.

```csharp
private readonly ReaderWriterLockSlim _rwLock = new();
private Dictionary<string, Data> _cache = new();

public Data? Read(string key)
{
    _rwLock.EnterReadLock();  // Multiple readers allowed
    try
    {
        return _cache.TryGetValue(key, out var data) ? data : null;
    }
    finally
    {
        _rwLock.ExitReadLock();
    }
}

public void Write(string key, Data data)
{
    _rwLock.EnterWriteLock();  // Exclusive access
    try
    {
        _cache[key] = data;
    }
    finally
    {
        _rwLock.ExitWriteLock();
    }
}
```

## Interlocked

Use `Interlocked` for atomic integer operations without locking - efficient for simple counters.

```csharp
private int _counter;

// Atomic operations - no lock needed
Interlocked.Increment(ref _counter);
Interlocked.Decrement(ref _counter);
Interlocked.Add(ref _counter, 5);
Interlocked.Exchange(ref _counter, 0);
Interlocked.CompareExchange(ref _counter, newValue, expectedValue);
```
