## Basic Exception Handling

Use try/catch around awaited calls to handle exceptions as you would with synchronous code; handle cancellations and specific exceptions like `HttpRequestException` explicitly.

```csharp
try
{
    var result = await GetDataAsync();
}
catch (HttpRequestException ex)
{
    // Handle network error
    logger.LogError(ex, "Network request failed");
}
catch (OperationCanceledException)
{
    // Handle cancellation
    logger.LogInformation("Operation was cancelled");
}
```

## AggregateException with WhenAll

`Task.WhenAll` throws when any task faults; the returned task captures all exceptions in `Exception.InnerExceptions` - iterate them to log all failures.

```csharp
var tasks = urls.Select(url => httpClient.GetStringAsync(url));
var allTask = Task.WhenAll(tasks);

try
{
    var results = await allTask;
}
catch (Exception)
{
    // Only first exception is thrown!
    // To get all exceptions:
    if (allTask.Exception != null)
    {
        foreach (var ex in allTask.Exception.InnerExceptions)
        {
            logger.LogError(ex, "Task failed");
        }
    }
}
```

## Exception Filters

Use exception filters (`when`) to conditionally handle exceptions based on state - useful to distinguish between expected cancellations and unexpected errors.

```csharp
try
{
    await DoWorkAsync(cancellationToken);
}
catch (OperationCanceledException) when (cancellationToken.IsCancellationRequested)
{
    // Intentional cancellation
    return null;
}
catch (OperationCanceledException)
{
    // Timeout or other cancellation
    throw new TimeoutException("Operation timed out");
}
catch (HttpRequestException ex) when (ex.StatusCode == HttpStatusCode.NotFound)
{
    return null;  // 404 is expected
}
catch (HttpRequestException ex)
{
    throw;  // Other HTTP errors are unexpected
}
```

## Fire-and-Forget Safety

Always handle exceptions in fire-and-forget tasks by capturing them and logging inside a wrapper to prevent silent failures.

```csharp
// ❌ Dangerous - exceptions are lost
_ = DoWorkAsync();  // Fire and forget

// ✅ Safe - capture exceptions
_ = Task.Run(async () =>
{
    try
    {
        await DoWorkAsync();
    }
    catch (Exception ex)
    {
        logger.LogError(ex, "Background task failed");
    }
});
```
