## What is TPL Dataflow?

Install the package and use dataflow blocks to build pipelines with parallelism and buffering; the package provides TransformBlock, ActionBlock, BufferBlock, etc.

```bash
dotnet add package System.Threading.Tasks.Dataflow
```

## Basic Blocks

Examples for common blocks: `TransformBlock` for transformations, `ActionBlock` for side-effects, and `BufferBlock` as a queue.

```csharp
// TransformBlock - transforms input to output
var transformBlock = new TransformBlock<string, int>(
    s => s.Length,
    new ExecutionDataflowBlockOptions { MaxDegreeOfParallelism = 4 });

// ActionBlock - performs action on input (no output)
var actionBlock = new ActionBlock<int>(
    n => Console.WriteLine($"Length: {n}"));

// BufferBlock - simple buffer/queue
var bufferBlock = new BufferBlock<string>();
```

## Building a Pipeline

Link blocks together with `LinkTo` and propagate completion to cascade shutdown through the pipeline.

```csharp
// Create blocks
var downloadBlock = new TransformBlock<string, string>(
    async url => await httpClient.GetStringAsync(url),
    new ExecutionDataflowBlockOptions { MaxDegreeOfParallelism = 5 });

var parseBlock = new TransformBlock<string, Document>(
    html => ParseHtml(html),
    new ExecutionDataflowBlockOptions { MaxDegreeOfParallelism = 10 });

var saveBlock = new ActionBlock<Document>(
    async doc => await SaveDocumentAsync(doc));

// Link blocks together
var linkOptions = new DataflowLinkOptions { PropagateCompletion = true };
downloadBlock.LinkTo(parseBlock, linkOptions);
parseBlock.LinkTo(saveBlock, linkOptions);

// Feed data
foreach (var url in urls)
    await downloadBlock.SendAsync(url);

// Signal completion and wait
downloadBlock.Complete();
await saveBlock.Completion;
```

## Bounded Capacity

Set `BoundedCapacity` on block options to limit memory usage and cause `SendAsync` to wait when the buffer is full.

```csharp
// Limit memory usage with bounded capacity
var options = new ExecutionDataflowBlockOptions
{
    BoundedCapacity = 100,  // Max 100 items in queue
    MaxDegreeOfParallelism = 4
};

var block = new TransformBlock<Input, Output>(Process, options);

// SendAsync will wait if buffer is full
await block.SendAsync(item);
```
