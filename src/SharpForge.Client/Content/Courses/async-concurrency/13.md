## ConcurrentDictionary

Thread-safe dictionary with atomic operations like `GetOrAdd` and `AddOrUpdate` which is good for caches.

```csharp
var cache = new ConcurrentDictionary<string, Data>();

// Thread-safe add or update
cache.TryAdd("key", new Data());
cache.AddOrUpdate("key", 
    addValue: new Data(),
    updateValueFactory: (key, existing) => new Data());

// Get or add atomically
var value = cache.GetOrAdd("key", key => LoadExpensiveData(key));

// Thread-safe read
if (cache.TryGetValue("key", out var data))
{
    // Use data
}
```

## ConcurrentQueue and ConcurrentStack

Non-blocking FIFO/LIFO collections suitable for producer-consumer scenarios without explicit locks.

```csharp
var queue = new ConcurrentQueue<WorkItem>();

// Producer
queue.Enqueue(new WorkItem());

// Consumer
if (queue.TryDequeue(out var item))
{
    ProcessItem(item);
}

// Stack (LIFO)
var stack = new ConcurrentStack<WorkItem>();
stack.Push(item);
stack.TryPop(out var popped);
```

## ConcurrentBag

Optimized for scenarios where the same thread both adds and removes frequently and provides thread-local storage for fast operations.

```csharp
// Thread-local storage optimized for add/take from same thread
var bag = new ConcurrentBag<Result>();

Parallel.ForEach(items, item =>
{
    var result = Process(item);
    bag.Add(result);  // Fast - uses thread-local storage
});

// Get all results
var allResults = bag.ToArray();
```

## BlockingCollection

Provides a bounded or unbounded blocking queue; producers block when full and consumers block when empty which is great for classic producer-consumer patterns.

```csharp
using var collection = new BlockingCollection<WorkItem>(boundedCapacity: 100);

// Producer
Task.Run(() =>
{
    foreach (var item in GetItems())
    {
        collection.Add(item);  // Blocks if full
    }
    collection.CompleteAdding();
});

// Consumer
foreach (var item in collection.GetConsumingEnumerable())
{
    ProcessItem(item);  // Blocks if empty
}
```
