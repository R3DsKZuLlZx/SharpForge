## Task.WhenAll

Run several tasks concurrently and await all of them; useful when you need every result and want to parallelize independent operations.

```csharp
// Run multiple operations concurrently
var userTask = GetUserAsync(userId);
var ordersTask = GetOrdersAsync(userId);
var prefsTask = GetPreferencesAsync(userId);

// Wait for all to complete
await Task.WhenAll(userTask, ordersTask, prefsTask);

// Access results
var user = await userTask;
var orders = await ordersTask;
var prefs = await prefsTask;

// Or get all results at once
var urls = new[] { "url1", "url2", "url3" };
var tasks = urls.Select(url => httpClient.GetStringAsync(url));
string[] results = await Task.WhenAll(tasks);
```

## Task.WhenAny

Use `WhenAny` to await the first completed task which is handy for timeouts or racing multiple sources.

```csharp
// Timeout pattern
var dataTask = GetDataAsync();
var timeoutTask = Task.Delay(TimeSpan.FromSeconds(5));

var completedTask = await Task.WhenAny(dataTask, timeoutTask);

if (completedTask == timeoutTask)
    throw new TimeoutException("Operation timed out");

var result = await dataTask;  // Get the actual result
```

## First Successful Result

Pattern to try multiple sources and return the first successful result while ignoring failures from others.

```csharp
// Try multiple sources, use first success
public async Task<Data> GetFromAnySourceAsync()
{
    var tasks = new List<Task<Data>>
    {
        GetFromCacheAsync(),
        GetFromDatabaseAsync(),
        GetFromApiAsync()
    };

    while (tasks.Count > 0)
    {
        var completed = await Task.WhenAny(tasks);
        tasks.Remove(completed);

        try
        {
            return await completed;  // Return first success
        }
        catch
        {
            // Try next one
        }
    }

    throw new Exception("All sources failed");
}
```

## Throttling Concurrent Operations

Use a `SemaphoreSlim` to limit concurrency when processing many items to avoid overloading resources.

```csharp
// Process with limited concurrency
public async Task ProcessAllAsync(IEnumerable<string> urls, int maxConcurrency = 10)
{
    var semaphore = new SemaphoreSlim(maxConcurrency);
    var tasks = urls.Select(async url =>
    {
        await semaphore.WaitAsync();
        try
        {
            await ProcessUrlAsync(url);
        }
        finally
        {
            semaphore.Release();
        }
    });

    await Task.WhenAll(tasks);
}
```
