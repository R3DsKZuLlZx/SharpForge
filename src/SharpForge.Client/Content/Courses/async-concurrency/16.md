## Visual Studio Parallel Stacks

Debug > Windows > Parallel Stacks (Ctrl+Shift+D, S)

- View all threads and their call stacks
- Toggle "Tasks" view for async operations
- See waiting, running, and scheduled tasks

## Tasks Window

Example output from the Tasks window showing task IDs, status, and description - useful to identify active vs waiting tasks while debugging.

```text
ID    Status          Description
1     Waiting         GetDataAsync
2     Running         ProcessItemAsync  
3     Scheduled       SaveResultAsync
```

## Async Stack Traces

Enable full debug symbols or use tools like Ben.Demystifier to get clearer async stack traces that show the logical call path across awaits.

```csharp
// Enable better async stack traces
<PropertyGroup>
    <DebugType>full</DebugType>
</PropertyGroup>

// Or use Ben.Demystifier package
try
{
    await DoWorkAsync();
}
catch (Exception ex)
{
    Console.WriteLine(ex.Demystify());
}
```

## Detecting Thread Pool Starvation

Collect ThreadPool metrics such as available threads vs max to detect starvation; low available threads and timeouts indicate pressure.

```csharp
// Monitor thread pool
ThreadPool.GetMinThreads(out int workerMin, out int ioMin);
ThreadPool.GetMaxThreads(out int workerMax, out int ioMax);
ThreadPool.GetAvailableThreads(out int workerAvail, out int ioAvail);

Console.WriteLine($"Workers: {workerMax - workerAvail}/{workerMax}");

// Signs of starvation:
// - Available threads near 0
// - Requests timing out
// - High CPU with low actual work
```

## dotnet-counters

Commands to install and monitor runtime counters like thread pool and queue lengths; useful for live diagnostics during load testing.

```bash
# Install
dotnet tool install -g dotnet-counters

# Monitor async metrics
dotnet counters monitor --process-id <pid> \
    --counters System.Runtime,Microsoft.AspNetCore.Hosting

# Key counters:
# - threadpool-thread-count
# - threadpool-queue-length
# - active-timer-count
```

## dotnet-trace for Profiling

```bash
# Collect trace
dotnet trace collect --process-id <pid> --duration 00:00:30

# Analyze with:
# - PerfView (Windows)
# - Speedscope (cross-platform, web)
# - Visual Studio
```
