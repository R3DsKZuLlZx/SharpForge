## The Principle

**"A class should have only one reason to change."**

Each class should focus on a single concern. If a class has multiple responsibilities, changes to one responsibility may affect the others.

## ❌ Violating SRP

```csharp
public class Employee
{
    public string Name { get; set; }
    public decimal Salary { get; set; }

    // Responsibility 1: Calculate pay
    public decimal CalculatePay() => Salary / 12;

    // Responsibility 2: Save to database
    public void Save() => Database.Save(this);

    // Responsibility 3: Generate report
    public string GenerateReport() => $"Employee: {Name}, Salary: {Salary}";
}
```

This class has THREE reasons to change: pay calculation, persistence, and reporting.

## ✅ Following SRP

```csharp
// Responsibility 1: Employee data
public class Employee
{
    public string Name { get; set; }
    public decimal Salary { get; set; }
}

// Responsibility 2: Pay calculation
public class PayCalculator
{
    public decimal CalculateMonthlyPay(Employee employee)
        => employee.Salary / 12;
}

// Responsibility 3: Persistence
public class EmployeeRepository
{
    public void Save(Employee employee) => Database.Save(employee);
}

// Responsibility 4: Reporting
public class EmployeeReportGenerator
{
    public string Generate(Employee employee)
        => $"Employee: {employee.Name}, Salary: {employee.Salary}";
}
```

## Real-World Example

```csharp
// ❌ Controller doing too much
public class OrderController
{
    public IActionResult CreateOrder(OrderDto dto)
    {
        // Validation
        if (string.IsNullOrEmpty(dto.CustomerEmail)) return BadRequest();
        
        // Business logic
        var order = new Order { Total = dto.Items.Sum(i => i.Price) };
        
        // Persistence
        _context.Orders.Add(order);
        _context.SaveChanges();
        
        // Email notification
        _emailService.Send(dto.CustomerEmail, "Order confirmed!");
        
        return Ok(order);
    }
}

// ✅ Separated responsibilities
public class OrderController
{
    private readonly IOrderService _orderService;
    
    public IActionResult CreateOrder(OrderDto dto)
    {
        var result = _orderService.CreateOrder(dto);
        return result.IsSuccess ? Ok(result.Value) : BadRequest(result.Error);
    }
}
```
