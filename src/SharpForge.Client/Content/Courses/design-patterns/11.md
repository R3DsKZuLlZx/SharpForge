## Intent

Create new objects by cloning existing ones, avoiding costly creation from scratch.

## ICloneable Interface

```csharp
public class Document : ICloneable
{
    public string Title { get; set; }
    public string Content { get; set; }
    public List<string> Tags { get; set; } = new();

    public object Clone()
    {
        // Shallow copy
        return MemberwiseClone();
    }
}

var original = new Document { Title = "Report", Content = "..." };
var copy = (Document)original.Clone();
```

## Deep Clone

```csharp
public class Document : ICloneable
{
    public string Title { get; set; }
    public string Content { get; set; }
    public List<string> Tags { get; set; } = new();

    public object Clone()
    {
        // Deep copy - clone reference types too
        var clone = (Document)MemberwiseClone();
        clone.Tags = new List<string>(Tags);  // New list with same items
        return clone;
    }
}

// Using JSON serialization for deep clone
public T DeepClone<T>(T obj)
{
    var json = JsonSerializer.Serialize(obj);
    return JsonSerializer.Deserialize<T>(json)!;
}
```

## Record Types (C# 9+)

```csharp
// Records have built-in with-expressions for cloning
public record Person(string Name, int Age, Address Address);
public record Address(string City, string Country);

var original = new Person("John", 30, new Address("London", "UK"));

// Clone with modifications
var clone = original with { Name = "Jane" };
var moved = original with { Address = original.Address with { City = "Paris" } };
```
