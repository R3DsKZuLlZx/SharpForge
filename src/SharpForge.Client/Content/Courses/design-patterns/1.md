## What Are Design Patterns?

Design patterns are reusable solutions to common problems in software design. They're not code you can copy directly—they're templates for solving problems that can be adapted to your specific situation.

## Why Learn Design Patterns?

- **Common vocabulary:** Communicate complex ideas quickly
- **Proven solutions:** Don't reinvent the wheel
- **Better design:** Write more maintainable code
- **Flexibility:** Make your code easier to change
- **Interview preparation:** Commonly asked in technical interviews

## When to Use Patterns

```csharp
// ❌ Don't force patterns where they don't fit
// This is YAGNI - You Aren't Gonna Need It

// ✅ Use patterns when:
// - You recognize a recurring problem
// - The pattern genuinely simplifies your code
// - You need flexibility for future changes
// - The team understands the pattern
```
