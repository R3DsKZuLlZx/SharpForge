## Intent

Convert the interface of a class into another interface that clients expect. Adapter lets classes work together that couldn't otherwise because of incompatible interfaces.

## The Problem

```csharp
// Your application expects this interface
public interface IPaymentGateway
{
    Task<bool> ChargeAsync(decimal amount, string currency);
}

// But the third-party library has a different interface
public class StripeClient
{
    public async Task<StripeCharge> CreateChargeAsync(StripeChargeRequest request)
    {
        // Stripe-specific implementation
    }
}
```

## The Adapter Solution

```csharp
public class StripeAdapter : IPaymentGateway
{
    private readonly StripeClient _stripeClient;

    public StripeAdapter(StripeClient stripeClient)
    {
        _stripeClient = stripeClient;
    }

    public async Task<bool> ChargeAsync(decimal amount, string currency)
    {
        var request = new StripeChargeRequest
        {
            Amount = (long)(amount * 100),  // Stripe uses cents
            Currency = currency.ToLower()
        };

        var result = await _stripeClient.CreateChargeAsync(request);
        return result.Status == "succeeded";
    }
}

// Your code works with the interface
public class PaymentService
{
    private readonly IPaymentGateway _gateway;

    public PaymentService(IPaymentGateway gateway) => _gateway = gateway;

    public async Task ProcessPayment(decimal amount)
    {
        await _gateway.ChargeAsync(amount, "USD");
    }
}
```

## Real-World Examples

- Wrapping legacy APIs
- Integrating third-party libraries
- Database provider adapters
- Logging framework adapters
