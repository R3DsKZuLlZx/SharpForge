## Intent

Ensure a class has only one instance and provide a global point of access to it.

## Thread-Safe Singleton (Lazy)

```csharp
public sealed class Logger
{
    private static readonly Lazy<Logger> _instance = 
        new(() => new Logger());

    public static Logger Instance => _instance.Value;

    private Logger() 
    {
        // Private constructor prevents external instantiation
    }

    public void Log(string message)
    {
        Console.WriteLine($"[{DateTime.Now}] {message}");
    }
}

// Usage
Logger.Instance.Log("Application started");
```

## Alternative: Static Initialization

```csharp
public sealed class Configuration
{
    // Eager initialization - thread-safe by CLR guarantee
    private static readonly Configuration _instance = new();

    public static Configuration Instance => _instance;

    private Configuration()
    {
        // Load configuration
    }

    public string ConnectionString { get; private set; }
}
```

## Modern Approach: Use DI Container

```csharp
// Register as singleton in DI
builder.Services.AddSingleton<ILogger, Logger>();
builder.Services.AddSingleton<IConfiguration>(config);

// Inject where needed - no static access!
public class OrderService
{
    private readonly ILogger _logger;

    public OrderService(ILogger logger)
    {
        _logger = logger;
    }
}
```

- Logging services
- Database connection pools
- Caches
