## See What's Happening

Logging and monitoring give you visibility into your API's behavior in production. In this lesson, you'll learn how to use ASP.NET Core's built-in logging, integrate Serilog for structured logging, and add health checks for monitoring.

## Built-in Logging

ASP.NET Core provides `ILogger<T>` through dependency injection:

```csharp
[ApiController]
[Route("api/[controller]")]
public class ProductsController : ControllerBase
{
    private readonly IProductService _productService;
    private readonly ILogger<ProductsController> _logger;

    public ProductsController(
        IProductService productService,
        ILogger<ProductsController> logger)
    {
        _productService = productService;
        _logger = logger;
    }

    [HttpGet("{id}")]
    public async Task<ActionResult<Product>> GetById(int id)
    {
        _logger.LogInformation("Getting product {ProductId}", id);

        var product = await _productService.GetByIdAsync(id);
        if (product is null)
        {
            _logger.LogWarning("Product {ProductId} not found", id);
            return NotFound();
        }

        return Ok(product);
    }
}
```

      "Default": "Information",

  }

## Serilog Integration

Serilog is the most popular structured logging library for .NET:

```bash
dotnet add package Serilog.AspNetCore
dotnet add package Serilog.Sinks.File
dotnet add package Serilog.Sinks.Seq  # Optional: for centralized logging
```

```csharp
using Serilog;

var builder = WebApplication.CreateBuilder(args);

builder.Host.UseSerilog((context, config) =>
{
    config
        .ReadFrom.Configuration(context.Configuration)
        .WriteTo.Console()
        .WriteTo.File("logs/api-.log",
            rollingInterval: RollingInterval.Day,
            retainedFileCountLimit: 30)
        .Enrich.FromLogContext()
        .Enrich.WithMachineName()
        .Enrich.WithEnvironmentName();
});

var app = builder.Build();

// Log every HTTP request with method, path, status, and duration
app.UseSerilogRequestLogging();

app.MapControllers();
app.Run();
```

Serilog configuration in `appsettings.json`:

```json
{
  "Serilog": {
    "MinimumLevel": {
      "Default": "Information",
      "Override": {
        "Microsoft.AspNetCore": "Warning"
      }
    }
  }
}
```

## Correlation IDs

Track a single request across multiple services:

```csharp
app.Use(async (context, next) =>
{
    var correlationId = context.Request.Headers["X-Correlation-Id"]
        .FirstOrDefault() ?? Guid.NewGuid().ToString();

    context.Response.Headers["X-Correlation-Id"] = correlationId;

    using (LogContext.PushProperty("CorrelationId", correlationId))
    {
        await next();
    }
});
```

## Health Checks

Health checks let monitoring tools verify your API is running:

```csharp
// Program.cs
builder.Services.AddHealthChecks()
    .AddDbContextCheck<AppDbContext>("database")
    .AddRedis(builder.Configuration.GetConnectionString("Redis")!,
        name: "redis")
    .AddCheck<DiskSpaceHealthCheck>("disk-space");

var app = builder.Build();

app.MapHealthChecks("/health", new HealthCheckOptions
{
    ResponseWriter = UIResponseWriter.WriteHealthCheckUIResponse
});
```

Custom health check:

```csharp
public class DiskSpaceHealthCheck : IHealthCheck
{
    public Task<HealthCheckResult> CheckHealthAsync(
        HealthCheckContext context,
        CancellationToken cancellationToken = default)
    {
        var drive = new DriveInfo("C");
        var freeGb = drive.AvailableFreeSpace / (1024.0 * 1024 * 1024);

        return Task.FromResult(freeGb switch
        {
            < 1 => HealthCheckResult.Unhealthy($"Low disk: {freeGb:F1} GB"),
            < 5 => HealthCheckResult.Degraded($"Disk space: {freeGb:F1} GB"),
            _ => HealthCheckResult.Healthy($"Disk space: {freeGb:F1} GB")
        });
    }
}
```

## Best Practices

- Use **structured logging** with message templates, not string interpolation
- Log at the **right level** — don't log everything as Information
- Include **context** (IDs, user info, correlation IDs) in log entries
- Never log **sensitive data** (passwords, tokens, PII)
- Use **health checks** for all external dependencies (database, cache, queues)
- Send logs to a **centralized platform** (Seq, Elastic, Application Insights) in production
