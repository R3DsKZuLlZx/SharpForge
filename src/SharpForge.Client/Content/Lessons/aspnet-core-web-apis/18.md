## Ship It!

You've built a full-featured API — now it's time to deploy it to production. In this lesson, you'll learn how to publish your API, containerize it with Docker, configure it for different environments, and set up a CI/CD pipeline.

## Publishing Your API

Create a production-ready build with the .NET CLI:

```bash
# Self-contained deployment (includes .NET runtime)
dotnet publish -c Release -o ./publish --self-contained true \
    -r linux-x64

# Framework-dependent (smaller, requires .NET on the server)
dotnet publish -c Release -o ./publish
```

The `publish` folder contains everything needed to run your API.

## Dockerizing Your API

Docker provides consistent deployments across all environments. Create a `Dockerfile`:

```dockerfile
# Build stage
FROM mcr.microsoft.com/dotnet/sdk:10.0 AS build
WORKDIR /src

COPY *.csproj .
RUN dotnet restore

COPY . .
RUN dotnet publish -c Release -o /app/publish

# Runtime stage
FROM mcr.microsoft.com/dotnet/aspnet:10.0
WORKDIR /app

COPY --from=build /app/publish .

EXPOSE 8080
ENV ASPNETCORE_URLS=http://+:8080

ENTRYPOINT ["dotnet", "ProductsApi.dll"]
```

Build and run:

```bash
docker build -t products-api .
docker run -p 8080:8080 products-api
```

## Docker Compose

For APIs with dependencies (database, cache), use Docker Compose:

```yaml
# docker-compose.yml
services:
  api:
    build: .
    ports:
      - "8080:8080"
    environment:
      - ConnectionStrings__DefaultConnection=Server=db;Database=Products;User=sa;Password=YourPassword123!
      - ASPNETCORE_ENVIRONMENT=Production
    depends_on:
      - db
      - redis

  db:
    image: mcr.microsoft.com/mssql/server:2022-latest
    environment:
      - ACCEPT_EULA=Y
      - SA_PASSWORD=YourPassword123!
    ports:
      - "1433:1433"

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
```

```bash
docker compose up -d
```

## Environment Configuration

ASP.NET Core loads configuration based on the `ASPNETCORE_ENVIRONMENT` variable:

```csharp
// Program.cs — configuration is loaded automatically
// appsettings.json              → always loaded
// appsettings.Development.json  → loaded when env is Development
// appsettings.Production.json   → loaded when env is Production
// Environment variables         → override file settings
```

```json
// appsettings.Production.json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=production-server;Database=Products;..."
  },
  "Logging": {
    "LogLevel": {
      "Default": "Warning"
    }
  }
}
```

## CI/CD with GitHub Actions

Automate your build and deployment pipeline:

```yaml
# .github/workflows/ci.yml
name: Build and Deploy

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build-and-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup .NET
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '10.0.x'

      - name: Restore dependencies
        run: dotnet restore

      - name: Build
        run: dotnet build --no-restore -c Release

      - name: Test
        run: dotnet test --no-build -c Release --verbosity normal

      - name: Publish
        run: dotnet publish -c Release -o ./publish

      - name: Build Docker image
        run: docker build -t products-api:${{ github.sha }} .
```

## CORS Configuration

If browser-based clients consume your API, configure CORS:

```csharp
builder.Services.AddCors(options =>
{
    options.AddPolicy("AllowFrontend", policy =>
    {
        policy.WithOrigins("https://yourfrontend.com")
              .AllowAnyHeader()
              .AllowAnyMethod();
    });
});

var app = builder.Build();
app.UseCors("AllowFrontend");
```
