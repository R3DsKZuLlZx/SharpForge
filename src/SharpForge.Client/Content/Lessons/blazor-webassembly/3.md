## Anatomy of a Razor Component

Below is a minimal component file showing common top-level directives (routing, usings, injection), markup, and an @@code block for component state.

```razor
@@* Directives at the top *@@
@@page "/my-component"
@@using MyApp.Models
@@inject HttpClient Http

@@* HTML Markup with Razor syntax *@@
<h1>@@title</h1>

<ul>
    @@foreach (var item in items)
    {
        <li>@@item.Name</li>
    }
</ul>

@@* C# Code Block *@@
@@code {
    private string title = "My Component";
    private List<Item> items = new();
}
```

## Razor Syntax Basics

The examples below demonstrate Razor syntax used inside .razor components: inline expressions, explicit expressions, code blocks, conditionals, and loops. They show how C# and markup interleave in a component.

```razor
@@* Implicit expressions *@@
<p>Hello, @@name!</p>
<p>Count: @@items.Count</p>

@@* Explicit expressions *@@
<p>Total: @@(price * quantity)</p>

@@* Code blocks *@@
@@{
    var greeting = "Hello";
    var target = "World";
}
<p>@@greeting, @@target!</p>

@@* Conditionals *@@
@@if (isVisible)
{
    <p>I'm visible!</p>
}
else
{
    <p>I'm hidden!</p>
}

@@* Loops *@@
@@foreach (var product in products)
{
    <div class="product">@@product.Name</div>
}
```

## Creating Reusable Components

This component example shows a ProductCard component using a `[Parameter]` to accept data and an event handler to respond to user actions, useful as a starting point for reusable UI pieces.

```razor
@@* Components/ProductCard.razor *@@
<div class="product-card">
    <h3>@@Product.Name</h3>
    <p class="price">@@Product.Price.ToString("C")</p>
    <button @@onclick="AddToCart">Add to Cart</button>
</div>

@@code {
    [Parameter]
    public Product Product { get; set; } = default!;

    private void AddToCart()
    {
        // Add to cart logic
    }
}
```

This shows how the component is used from a parent: pass the product instance via the `Product` parameter.

```razor
@@* Using the component *@@
<ProductCard Product="@@myProduct" />
```

## Component CSS Isolation

Create a `.razor.css` file with the same name as your component:

```css
/* ProductCard.razor.css */
.product-card {
    border: 1px solid #ccc;
    padding: 1rem;
    border-radius: 8px;
}

.price {
    color: green;
    font-weight: bold;
}
```

Styles are automatically scoped to the component!
