## RabbitMQ for .NET Microservices

RabbitMQ is one of the most popular message brokers for microservices. It's open-source, battle-tested, and has excellent .NET support. In this lesson you'll learn to publish and consume messages using **MassTransit**, a popular .NET abstraction that simplifies working with RabbitMQ.

## RabbitMQ Concepts

- **Producer** — sends messages to an exchange.
- **Exchange** — routes messages to queues based on rules (bindings).
- **Queue** — stores messages until a consumer processes them.
- **Consumer** — reads and processes messages from a queue.
- **Binding** — a rule connecting an exchange to a queue.

## Running RabbitMQ with Docker

```yaml
# docker-compose.yml
services:
  rabbitmq:
    image: rabbitmq:3-management
    ports:
      - "5672:5672"    # AMQP protocol
      - "15672:15672"  # Management UI
    environment:
      - RABBITMQ_DEFAULT_USER=guest
      - RABBITMQ_DEFAULT_PASS=guest
    healthcheck:
      test: rabbitmq-diagnostics -q check_running
      interval: 10s
      timeout: 5s
      retries: 5
```

Access the management UI at `http://localhost:15672` with `guest/guest`.

## Setting Up MassTransit

MassTransit provides a clean abstraction over RabbitMQ (and other transports):

```bash
dotnet add package MassTransit.RabbitMQ
```

Configure in `Program.cs`:

```csharp
builder.Services.AddMassTransit(x =>
{
    // Register consumers from the current assembly
    x.AddConsumers(typeof(Program).Assembly);

    x.UsingRabbitMq((context, cfg) =>
    {
        cfg.Host("rabbitmq", "/", h =>
        {
            h.Username("guest");
            h.Password("guest");
        });

        // Auto-configure endpoints for all registered consumers
        cfg.ConfigureEndpoints(context);
    });
});
```

## Publishing Events

Use `IPublishEndpoint` to publish events:

```csharp
public class OrderController : ControllerBase
{
    private readonly IPublishEndpoint _publisher;
    private readonly IOrderRepository _orders;

    public OrderController(IPublishEndpoint publisher, IOrderRepository orders)
    {
        _publisher = publisher;
        _orders = orders;
    }

    [HttpPost]
    public async Task<IActionResult> PlaceOrder(PlaceOrderRequest request)
    {
        var order = Order.Create(request.CustomerId, request.Items);
        await _orders.AddAsync(order);

        await _publisher.Publish(new OrderPlacedEvent
        {
            OrderId = order.Id,
            CustomerId = order.CustomerId,
            TotalAmount = order.Total,
            OccurredAt = DateTime.UtcNow
        });

        return CreatedAtAction(nameof(GetOrder), new { id = order.Id }, order);
    }
}
```

## Consuming Events

Create a consumer class:

```csharp
public class OrderPlacedConsumer : IConsumer<OrderPlacedEvent>
{
    private readonly IStockRepository _stock;
    private readonly ILogger<OrderPlacedConsumer> _logger;

    public OrderPlacedConsumer(IStockRepository stock, ILogger<OrderPlacedConsumer> logger)
    {
        _stock = stock;
        _logger = logger;
    }

    public async Task Consume(ConsumeContext<OrderPlacedEvent> context)
    {
        var message = context.Message;
        _logger.LogInformation("Processing OrderPlaced: {OrderId}", message.OrderId);

        foreach (var item in message.Items)
        {
            await _stock.ReserveAsync(item.ProductId, item.Quantity);
        }

        _logger.LogInformation("Stock reserved for order {OrderId}", message.OrderId);
    }
}
```

MassTransit automatically creates the exchange, queue, and bindings when the consumer starts.

## Sending Commands

For point-to-point commands, use `ISendEndpointProvider`:

```csharp
public class PaymentService
{
    private readonly ISendEndpointProvider _sender;

    public PaymentService(ISendEndpointProvider sender) => _sender = sender;

    public async Task RequestPaymentAsync(Guid orderId, decimal amount)
    {
        var endpoint = await _sender.GetSendEndpoint(
            new Uri("queue:process-payment"));

        await endpoint.Send(new ProcessPaymentCommand
        {
            OrderId = orderId,
            Amount = amount,
            Currency = "USD"
        });
    }
}
```

## Error Handling and Retries

Configure retry and error policies:

```csharp
x.UsingRabbitMq((context, cfg) =>
{
    cfg.Host("rabbitmq");

    cfg.UseMessageRetry(r =>
    {
        r.Incremental(3, TimeSpan.FromSeconds(1), TimeSpan.FromSeconds(2));
    });

    // Failed messages go to _error queue after retries are exhausted
    cfg.ConfigureEndpoints(context);
});
```

## Best Practices

- Use **MassTransit** instead of the raw RabbitMQ client for productivity and consistency
- **Publish events, send commands** — use the right verb for the right message type
- Configure **retries with backoff** for transient failures
- Monitor **queue depth** and **error queues** in the RabbitMQ management UI
- Use **durable queues** (the default in MassTransit) so messages survive broker restarts
- Keep message contracts in a **shared NuGet package** consumed by producers and consumers
