## Building an API Gateway with YARP

**YARP** is a reverse proxy library built by Microsoft specifically for .NET. It runs as ASP.NET Core middleware, so you get the full power of the .NET ecosystem: dependency injection, configuration, middleware pipeline, and native performance.

## Getting Started

Create a new gateway project and add the YARP package:

```bash
dotnet new web -n ApiGateway
cd ApiGateway
dotnet add package Yarp.ReverseProxy
```

## Configuration-Based Setup

The simplest approach — define routes and clusters in `appsettings.json`:

```json
{
  "ReverseProxy": {
    "Routes": {
      "orders-route": {
        "ClusterId": "orders-cluster",
        "Match": {
          "Path": "/api/orders/{**catch-all}"
        },
        "Transforms": [
          { "PathRemovePrefix": "/api/orders" }
        ]
      },
      "inventory-route": {
        "ClusterId": "inventory-cluster",
        "Match": {
          "Path": "/api/inventory/{**catch-all}"
        },
        "Transforms": [
          { "PathRemovePrefix": "/api/inventory" }
        ]
      }
    },
    "Clusters": {
      "orders-cluster": {
        "Destinations": {
          "orders-service": {
            "Address": "http://order-service:8080"
          }
        },
        "HealthCheck": {
          "Active": {
            "Enabled": true,
            "Interval": "00:00:30",
            "Path": "/health"
          }
        }
      },
      "inventory-cluster": {
        "Destinations": {
          "inventory-service": {
            "Address": "http://inventory-service:8080"
          }
        }
      }
    }
  }
}
```

Wire it up in `Program.cs`:

```csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddReverseProxy()
    .LoadFromConfig(builder.Configuration.GetSection("ReverseProxy"));

var app = builder.Build();
app.MapReverseProxy();
app.Run();
```

That's it — requests to `/api/orders/123` are forwarded to `http://order-service:8080/123`.

## Load Balancing

Distribute traffic across multiple instances of a service:

```json
{
  "orders-cluster": {
    "LoadBalancingPolicy": "RoundRobin",
    "Destinations": {
      "orders-1": { "Address": "http://order-service-1:8080" },
      "orders-2": { "Address": "http://order-service-2:8080" },
      "orders-3": { "Address": "http://order-service-3:8080" }
    }
  }
}
```

Available policies: `RoundRobin`, `Random`, `LeastRequests`, `PowerOfTwoChoices`, `FirstAlphabetical`.

## Authentication and Authorization

YARP integrates with ASP.NET Core authentication. Add auth to specific routes:

```csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddAuthentication("Bearer")
    .AddJwtBearer(options =>
    {
        options.Authority = "https://identity-server";
        options.Audience = "api-gateway";
    });
builder.Services.AddAuthorization();

builder.Services.AddReverseProxy()
    .LoadFromConfig(builder.Configuration.GetSection("ReverseProxy"));

var app = builder.Build();
app.UseAuthentication();
app.UseAuthorization();
app.MapReverseProxy();
app.Run();
```

```json
{
  "orders-route": {
    "ClusterId": "orders-cluster",
    "AuthorizationPolicy": "default",
    "Match": {
      "Path": "/api/orders/{**catch-all}"
    }
  }
}
```

## Rate Limiting

Use the built-in ASP.NET Core rate limiter with YARP:

```csharp
builder.Services.AddRateLimiter(options =>
{
    options.AddFixedWindowLimiter("api-limit", opt =>
    {
        opt.PermitLimit = 100;
        opt.Window = TimeSpan.FromMinutes(1);
        opt.QueueLimit = 10;
    });
});

var app = builder.Build();
app.UseRateLimiter();
app.MapReverseProxy();
```

```json
{
  "orders-route": {
    "RateLimiterPolicy": "api-limit",
    "ClusterId": "orders-cluster",
    "Match": { "Path": "/api/orders/{**catch-all}" }
  }
}
```

## Request and Response Transforms

YARP supports transforming requests and responses as they pass through:

```json
{
  "orders-route": {
    "ClusterId": "orders-cluster",
    "Match": { "Path": "/api/orders/{**catch-all}" },
    "Transforms": [
      { "PathRemovePrefix": "/api/orders" },
      { "RequestHeader": "X-Forwarded-By", "Set": "api-gateway" },
      { "ResponseHeader": "X-Gateway", "Set": "yarp", "When": "Always" }
    ]
  }
}
```

## Docker Compose Integration

```yaml
services:
  api-gateway:
    build:
      context: .
      dockerfile: ApiGateway/Dockerfile
    ports:
      - "5000:8080"
    depends_on:
      - order-service
      - inventory-service

  order-service:
    build:
      context: .
      dockerfile: OrderService/Dockerfile

  inventory-service:
    build:
      context: .
      dockerfile: InventoryService/Dockerfile
```

## Best Practices

- **Start with configuration-based routing** — it covers most scenarios
- Use **health checks** so YARP stops routing to unhealthy instances
- Add **authentication at the gateway** to reject unauthenticated requests early
- Enable **rate limiting** to protect backend services from abuse
- Use **path transforms** to keep backend service URLs clean
- Keep the gateway **stateless** so you can scale it horizontally
